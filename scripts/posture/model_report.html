Moti 모델·데이터 검사실

실제로 학습한 데이터, 사람별 검증 결과, 틀린 사례를 한곳에서 확인합니다.

현재 앱과 이 모델의 관계

현재 목·어깨 점수는 개인 기준과 비교하는 규칙 기반 계산입니다. 학습 모델은 골반이 보이고 기준/현재 품질 조건과 기하 변화가 모두 맞을 때만 목 원점수에 최대 12.5점 보조합니다. 골반 없는 통상 구도에서는 기여가 0이며 기본 관측은 계속됩니다. 아래 성능은 거북목 진단 정확도가 아닙니다.

데이터에는 사진이나 원본 영상이 없습니다. 아래 그림은 제공된 33개 관절 좌표를 그린 것입니다. 골반을 요구하지 않는 모델을 만들려면 해당 구도로 독립 정답을 수집하고 새 특징·검증을 설계해야 합니다.

현재 앱 점수의 크기 변화 안정성

같은 정지 사진을 0.75배/1.2배로 바꿔 MediaPipe Full을 다시 실행하고, 점수가 얼마나 바뀌는지 비교했습니다. 숫자가 작을수록 같은 자세에 대한 흔들림이 적습니다. 거북목 정답을 맞힌 비율이나 실제 동영상 성능은 아닙니다.

어떻게 학습했는지, 처음부터

  1. 자료 선택: 공개 MultiPosture의 관절 좌표 CSV를 받았습니다. 실제 파일은 13명의 4,794행입니다. 자세 라벨은 연구자가 제공한 몸통 분류이며, Moti 점수를 정답으로 만들지 않았습니다.
  2. 숫자로 바꾸기: 코·양어깨·양골반의 3D 좌표에서 머리/몸통 방향과 어깨 기울기에 해당하는 7개 비율을 만들었습니다. 어깨 폭으로 나누어 전체 크기의 영향을 줄였습니다. 좌우 기울임은 한 분류로 묶었습니다.
  3. 한 사람을 숨기고 학습: 12명으로만 평균·표준편차·허용 범위를 구하고 작은 신경망(입력 7 → 중간 16 → 출력 4)을 학습했습니다. 600번 Adam으로 가중치를 갱신했고, 사람·분류 수의 불균형을 보정했습니다.
  4. 숨긴 사람으로 시험: 학습에 들어가지 않은 1명의 분류를 예측했습니다. 이를 13번 반복했습니다(LOSO). 아래 개별 예측과 정확도는 모두 해당 사람을 제외한 모델의 결과입니다. 같은 자료를 외운 성적을 보여주지 않습니다.
  5. 모르는 경우 보류: 학습 범위 밖, 최댓값 0.85 미만 또는 상위 두 분류 차이 0.25 미만은 보류합니다. 확신도는 정답일 확률로 보정된 값이 아닙니다. 보류한 행을 맞힌 것으로 세지 않습니다.
  6. 최종 파일: 검증 후 13명 전체로 학습한 가중치도 별도 저장했습니다. 공개 데이터는 MediaPipe Heavy, Moti는 Full이라 입력 분포가 다릅니다. Moti의 실제 카메라 정확도·가림·시간 안정성은 이 검증으로 입증되지 않았습니다.
