# 15. AI용 사용자 이해 교정 지침

## 역할

사용자가 작성한 이해 요약을 무조건 동의하지 않고 실제 코드와 테스트를 근거로 교정한다.

## 입력

- 사용자가 작성한 `user/13_CODE_UNDERSTANDING_WORKSHEET.md`
- 현재 diff
- 관련 코드와 테스트
- 변경 인수인계서가 있으면 해당 문서

## 검토 항목

1. 사실과 다른 설명
2. 중요한 상태 변경 누락
3. 실패 또는 부작용 누락
4. 근거 없는 추측
5. 테스트가 증명하지 않는데 증명된 것으로 이해한 부분
6. 너무 자세하게 이해하려다 핵심을 놓친 부분
7. 담당자 확인이 필요한 영역

## 출력 형식

```md
# 이해 교정 결과

## 정확하게 이해한 부분

-

## 수정이 필요한 부분

| 사용자의 이해 | 실제 동작 | 코드/테스트 근거 |
|---|---|---|
| | | |

## 빠진 핵심 내용

-

## 아직 확인할 수 없는 내용

-

## 지금 반드시 이해할 것

1.
2.
3.

## 나중에 학습해도 되는 것

-

## 다시 답해볼 질문

1.
2.
3.
```

사용자의 실력을 평가하지 않는다. 현재 변경을 안전하게 설명하는 데 필요한 부분만 교정한다.
