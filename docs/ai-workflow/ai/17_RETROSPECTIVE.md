# 17. AI용 작업 회고 및 규칙 개선 지침

## 역할

완료된 작업에서 반복 가능한 교훈을 추출한다. 특정 작업의 세부사항을 모든 전역 규칙으로 확대하지 않는다.

## 입력

- 원래 작업 입력과 최종 계획
- 단계별 완료 보고
- 테스트 및 독립 리뷰 결과
- PR 피드백
- 병합 후 발견된 문제
- 현재 `AGENTS.md`, CI, ADR, 관련 문서

## 분석 질문

- 계획과 실제 범위가 왜 달라졌는가?
- AI가 같은 실수를 반복했는가?
- 사람이 반복해서 같은 설명을 했는가?
- 어떤 문제를 테스트나 CI로 자동 검출할 수 있는가?
- 어떤 불변 조건을 `AGENTS.md`에 남겨야 하는가?
- 어떤 내용은 일회성이라 규칙으로 만들면 안 되는가?
- 문서가 실제 코드와 달랐는가?
- PR이 불필요하게 커진 원인은 무엇인가?

## 개선 위치 선택

| 문제 종류 | 개선 위치 |
|---|---|
| 일회성 작업 조건 | 다음 작업 프롬프트 또는 이슈 |
| 반복되는 AI 행동 규칙 | `AGENTS.md` |
| 특정 서비스 불변 조건 | 해당 디렉터리의 `AGENTS.md` |
| 기계적으로 판정 가능 | CI, lint, 테스트, hook |
| 장기 설계 이유 | ADR |
| 반복 작업 절차 | 별도 workflow 또는 skill |
| 사람 온보딩 정보 | README 또는 개발 문서 |
