완료. 날짜/목·어깨/정책별 실제 통계와 기존 일/주/월 달력·목록·상세 흐름을 SQLite 조회에 연결했다.

## 계획과 달라진 점
최장 연속 관찰은 포함 기록 전체라는 범위를 명시했다. 새 기능 범위 없음.

## 변경 전과 변경 후
고정 예시 점수/이력과 무관한 localStorage 삭제 → SQLite 실제 조회와 현재 계정 삭제. AI/의학 예시는 별도 안내 후 유지.

## 영향을 받는 계약
현재 작업의 조회 DTO/UI만 변경. 기존 HTTP API와 카메라/점수 정책 유지. 삭제 generation으로 늦은 저장 요청 무효화.

## 테스트와 검사
타입/린트, 실제 표시 컴포넌트 SSR 통과. 이후 전체 front94 및 실제 Electron 통계 모드 전환/일·주·월/상세/삭제 취소·승인 검증은 09 기록 참조.

## 실행하지 못한 검사
실제 촬영·설치·장기간 운영. 자동 검증은 합성 데이터와 격리 프로필 사용.

## 남은 위험과 가정
현재 계정은 데모 계정 분리 기준, 진짜 서비스 인증이 아님. 저장 실패·조회 오류는 예시 데이터로 대체하지 않음.

## 사용자가 확인할 부분
실측 통계와 예시 AI/의학 정보를 구분하고 삭제가 현재 계정의 로컬 기록에만 적용됨을 확인.
