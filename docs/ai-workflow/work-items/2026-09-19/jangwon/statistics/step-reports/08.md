# 단계 8 보고: SQLite 프로젝트 상대경로

## 변경
- Electron main이 기본 DB 경로를 저장소 상대 `database/sqlite/posture.sqlite`로 계산하도록 분리했다.
- 기존 userData DB와 WAL은 새 DB가 없을 때만 한 번 복사하고 원본을 보존한다.
- 실제 Electron 검사는 환경 변수로 격리된 임시 DB 경로를 사용한다.
- 런타임 DB/WAL을 Git ignore에 추가하고 운영 문서와 작업 문서를 현재 계약에 맞췄다.

## 제한
- 실행 중인 앱이 실제 AppData DB/WAL을 새 경로로 자동 복사했다. 원본은 변경 없이 남았고 원본/대상 해시, `quick_check`, records·buckets 수가 일치했다.
