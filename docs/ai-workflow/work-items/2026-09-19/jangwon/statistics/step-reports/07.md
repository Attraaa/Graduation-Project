## 계획과 달라진 점
샌드박스 GPU 제약으로 실제 Electron 테스트는 승인된 정상 Windows 환경에서 실행. 빌드는 같은 Vite 설정에 configLoader runner 사용. 최장 연속 관찰은 포함 기록 전체라는 범위를 표시. 새 제품 범위 없음.

## 변경 전과 변경 후
예시 통계/이력 → 목·어깨 실제 로컬 기록. 저장 없는 종료 → 배치 저장/종료 flush/재시작 중단 복구.

## 영향을 받는 계약
새 로컬 기록/IPC/DB 계약만 추가. 기존 Express/Python/점수/카메라 정책 유지. production dependency 추가 없음.

## 테스트와 검사
전체 check exit0, frontend 최종94, server26, Python2. UI/Electron 빌드 성공. 실제 Electron seed/verify 통과. 종료 실패 service 보강 통과. 구체적 명령과 한계는 09_VERIFICATION.md.
