# 단계 완료 보고: 4 측정 기록 연결
## 결과
완료. 모든 계산 결과의 기록기, 누적 시간 버킷, 고정 재시도 batch, 종료 flush와 저장 오류 표시를 연결.
## 변경한 파일
- database/recorder.ts: UI 주기와 독립된 캡처/시간 분할/재시도.
- front/src/features/records/recording.ts, RecordingStatus.tsx: 로컬 계정 시작·재시도·삭제 무효화·종료 처리.
- PostureMonitor.tsx, PostureSession.tsx: 최소 기록 callback 및 종료 시 측정 중지.
- database/contracts.ts, front/electron/main.ts, preload.ts: 종료 handshake.
- front/tests/record-capture.test.mjs, record-service.test.mjs: 자정/누락/재시도/긴 구간/늦은 응답/실제 repository 연결.
## 계획과 달라진 점
백로그는 120개 이하 분 버킷 batch로 순차 저장. 실제 기록 상태를 보존하며 최종 저장 때 finished 처리.
## 변경 전과 변경 후
화면 상태만 존재 → 계정별 SQLite 기록, 재수집/모드 이동/중지에서 마지막 구간 저장.
## 영향을 받는 계약
카메라/점수 산식 유지. onClosing은 저장 실패 시 닫기 전 사용자에게 재시도/미저장 폐기 선택 제공.
## 테스트와 검사
캡처/서비스 8개(공통 계약 3 포함) 통과, 타입/린트 검사. 기존 산식 변경 없음.
## 실행하지 못한 검사
실제 카메라 촬영/OS 강제 종료는 미검증. 합성 입력과 실제 임시 SQLite로 확인.
## 남은 위험과 가정
강제 종료 직전 미커밋 구간 유실 가능. 로컬 데모 계정은 보안 인증 아님.
## 사용자가 확인할 부분
추가 승인 필요 없음.
