# Codex에서 변경 사항을 PR로 보내기

1. Codex 프로젝트의 기본 폴더를 이 저장소의 루트로 지정합니다. 루트에는 `AGENTS.md`와 `README.md`가 있습니다.
2. 작업 지침을 읽고 별도 작업 브랜치에서 파일을 수정합니다.
3. 변경 내용을 검토하고 작업 범위에 맞는 검사를 실행합니다.
4. 변경 파일을 커밋하고 GitHub의 작업 브랜치로 푸시합니다. GitHub 인증과 업로드 권한이 필요합니다.
5. 작업 브랜치에서 `main`을 대상으로 PR을 만듭니다. 연결 확인용 PR은 Draft로 생성합니다.
6. PR의 파일 변경과 검사 결과를 확인한 뒤 병합 여부를 결정합니다.

파일 수정, 커밋, 푸시, PR 생성, 병합은 각각 별도 단계입니다. PR 생성만으로 `main`에 변경이 반영되지는 않습니다.
