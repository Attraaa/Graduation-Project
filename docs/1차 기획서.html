Section 01

서비스 개요 · 앱 진입 흐름

PostureAI는 설치형 실행파일로 제공되는 AI 자세 학습 앱입니다. 사용자는 개인정보 동의 후 로그인하거나 회원가입하고, 대시보드에서 학습 모드를 선택해 웹캠 기반 자세 분석을 실행합니다.

핵심 흐름은 설치파일 실행, 개인정보 동의, 앱 실행, 로그인/회원가입, 대시보드 진입, 학습 모드 선택, 웹캠 설정, 학습 실행, 알림 및 통계 확인으로 이어집니다. 학습 종료 시에는 화면을 이동하지 않고 해당 학습 페이지에서 분석만 멈춘 상태로 유지합니다.

주요 기능 범위

구분범위기능 설명

Section 04

설치 · 개인정보 동의 · 인증

앱 첫 사용 흐름은 설치파일에서 시작하고, 개인정보 동의 후 실행파일을 통해 로그인 또는 회원가입 화면으로 진입합니다.

설치파일
Windows 설치파일. 설치 완료 후 바탕화면 또는 시작 메뉴 실행파일 제공.
개인정보 동의
카메라 사용, 자세 분석 데이터, 학습 이력 저장에 대한 동의. 동의해야 앱 사용 가능.
로그인
기존 계정으로 로그인. 로그인 성공 시 대시보드 이동.
회원가입
이름, 이메일, 비밀번호를 DB에 저장. 중복 이메일, 비밀번호 정책, 개인정보 동의 여부 검증 필요.

인증 관련 DB 필요 항목

테이블필드 예시설명
usersid, email, password_hash, username회원가입과 로그인 인증의 기준 데이터
privacy_consentsuser_id, camera_agreed, data_agreed, agreed_at개인정보 및 카메라 사용 동의 기록
auth_sessionsuser_id, refresh_token, expires_at자동 로그인 또는 세션 유지가 필요할 때 사용

Section 06

알림창 · AI 피드백

자세가 나빠지거나 설정한 조건을 만족하면 윈도우 알림처럼 오른쪽 하단에 알림을 띄우고, 학습 결과는 AI 피드백으로 요약합니다.

PostureAI 자세 알림
거북목 위험 자세가 지속되고 있습니다. 목을 뒤로 당기고 모니터 높이를 조정해 주세요.
오른쪽 하단 알림
윈도우 알림창처럼 화면 오른쪽 하단에 나타나는 toast 형태. 앱 내부 알림과 OS 알림을 함께 고려.
알림 빈도
설정창에서 즉시, 5분, 10분, 30분 등 빈도 조절. 너무 잦은 알림 방지.
알림 세기
약함, 보통, 강함 등 단계. 색상, 소리, 강조 애니메이션 강도에 반영.
AI 피드백
자체 API에 학습 요약 데이터를 보내고 시스템 프롬프트를 붙여 맞춤형 조언 생성.
AI Feedback Prompt// 서버에서 시스템 프롬프트와 학습 데이터를 조합 system: 너는 VDT 증후군 예방을 돕는 자세 코치다. 사용자의 학습 모드, 점수, 경고 횟수, 학습 시간을 바탕으로 짧고 실천 가능한 피드백을 한국어로 제공한다. user: { mode: "turtle", score: 72, warningCount: 14, durationMinutes: 35 }

Section 10

개발 로드맵

현재 프론트 구조를 기반으로 실제 앱 흐름을 완성하기 위한 단계별 개발 순서입니다.

PHASE 0 — 현재
Electron + React + MediaPipe 프로토타입
대시보드, 모드 카드, 웹캠 연결, MediaPipe Pose 기반 관절 표시 및 거북목 점수 계산 프로토타입.
PHASE 1 — 앱 진입 완성
설치, 개인정보 동의, 로그인/회원가입 DB 연동
설치 후 최초 실행 플로우, 동의 화면, 회원가입 저장, 로그인 인증, 자동 로그인 여부 처리.
