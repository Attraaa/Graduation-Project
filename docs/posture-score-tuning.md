# 상체 v6 점수 조절 기준

2026-10-19. 비교 UI: GitHub main `7753e71`. 실제 웹캠 피드백을 반영한 **잠정 제품 기준**입니다. 같은 상대 변화·같은 유효 지속 시간에는 같은 규칙을 적용하지만, 체형별 해부학적 심각도를 동일하게 측정한다고 보장하지 않습니다. 기본 기준 수집과 머리만 전진하는 v5 관측은 유지합니다. 점수는 계속 0~100이며, 고정된 자세의 기본 점수가 50점이라고 해서 최종 점수가 50점에 멈추는 제한을 없앴습니다.

## 조절할 파일

[scoreSettings.ts](../front/src/features/posture/scoreSettings.ts)의 `NECK_SUSTAINED`와 `SHOULDER_CURVE`를 수정하고 앱을 재실행해 **새 측정**을 시작합니다. 배포판은 다시 빌드해야 합니다. 값은 정책 ID 해시에 포함되어 다른 설정의 과거 기록과 통계가 섞이지 않습니다. 설정 화면의 ‘자세 무너짐 민감도’는 기존처럼 이탈 횟수 집계만 바꾸며 아래 감점 설정을 바꾸지 않습니다.

## 목: 80점대 전진도 오래 이어지면 추가 감점

기본 점수는 `0.35×머리 전진 + 0.25×모델 보조 + 0.4×높이 감소`를 이전과 동일하게 환산합니다. 아래 조건은 모델 보조를 빼고 판단합니다.

| 설정 | 기본값 | 의미 / 바꾸면 달라지는 점 |
| --- | --- | --- |
| `minHeadForward` | 0.16 | 보정된 머리 전진 입력의 최소값. 낮추면 작은 머리 움직임에도 발동 가능 |
| `minGeometryDeviation` | 0.065 | `0.35×머리 전진 + 0.4×높이 감소`의 최소값. 낮추면 덜 큰 이탈에서도 발동 |
| `delayMs` | 5000ms | 위 **두 조건을 모두** 만족하는 연속 정지 관측 대기 시간 |
| `pointsPerSecond` | 2점/초 | 대기 이후 추가 감점 속도. 1이면 5초당 5점, 2이면 5초당 10점 |
| `recoveryHeadForward` | 0.12 | 복귀 조건 A: 머리 전진이 이 값 이하 |
| `recoveryGeometryDeviation` | 0.045 | 복귀 조건 B: 모델을 제외한 기하 편차가 이 값 이하 |
| `recoveryMs` | 1000ms | A 또는 B가 연속 확인되면 누적 추가 감점을 해제 |

머리 입력 0.16은 16도나 16cm가 아닙니다. 머리 반응 gain 2, 원근 허용, 폭/추정 깊이 결합 이후의 값입니다. 두 진입 조건 덕분에 기준 범위·아주 작은 변화, 머리 전진 없는 처짐, 학습 모델 분류만으로는 추가 감점하지 않습니다. 모델 없이 기본 점수가 약 84.4점 이하일 정도의 기하 변화와 최소 머리 전진을 함께 요구하는 조정 설정입니다. 이전 0.10 경계(약 62.5점)에서는 80점대가 제외됐습니다. 순간 점수 산식을 그대로 두고 지속 감점의 대상을 넓혔으며, 점수가 실제 신체 부담을 정량 측정한다는 의미는 아닙니다.

`추가 감점 = 이전 추가 감점 + 2 × max(0, 이번에 새로 확인한 5초 초과 시간[초])`

`목 목표 점수 = max(0, 기본 점수 - 추가 감점)`

| 조건을 만족하는 전진을 연속 관측한 시간 | 기본 80점의 목표 점수 | 기본 50점의 목표 점수 |
| --- | --- | --- |
| 5초 | 80점 | 50점 |
| 10초 | 70점 | 40점 |
| 15초 | 60점 | 30점 |
| 20초 | 50점 | 20점 |
| 30초 | 30점 | 0점 |
| 45초 | 0점 | 0점 |

정확히 같은 점수가 반복되는지를 검사하지는 않습니다. 인식 잡음으로 소수점이 계속 바뀌어도 **전진 조건과 지속 시간**으로 판단합니다. 따라서 점수가 평탄해진 경우뿐 아니라 전진이 더 심해지는 도중에도 조건을 만족하면 누적합니다.

- 벽시계 시간이 아닌 유효한 연속 영상 간격(최대 500ms)만 셉니다. 첫 프레임은 시간을 더하지 않습니다.
- 빠른 움직임·가림·회전·일시정지·긴 공백은 대기 시간을 끊습니다. 다시 관측하면 5초부터 새로 확인합니다. 이미 받은 추가 감점은 보존하여 카메라를 가렸다는 이유로 점수가 올라가지 않게 합니다.
- 두 진입 조건 중 하나라도 벗어나면 새 감점은 멈춥니다. 복귀 경계까지 돌아오지 않았다면 기존 추가 감점은 유지합니다. 복귀 조건은 1초간 실제로 확인해야 하며 움직임·누락은 이 확인도 끊습니다.
- 원래의 움직임 동결, 2초 유예, 초당 최대 35점 하락, 100점 복귀 1초 확인은 유지합니다. 위 표는 목표 점수이며 실제 표시에는 이 보호가 먼저 적용됩니다.
- 새 세션·기준 재수집·정책 변경은 추가 감점을 초기화합니다. 평균과 서버 기록은 **추가 감점을 포함한 실제 표시 점수**를 시간 가중 누적합니다. 누락 구간을 채워 넣지 않습니다.
- 복귀 경계는 진입 경계보다 낮게, 시간·속도는 양수로 유지하세요. 기준 수집이 잘못됐거나 입력이 틀렸을 때 이 규칙이 자동으로 교정해 주지는 않습니다.

## 어깨: 작은 기울기는 유지하고 큰 각도는 지수 감점

현재와 기준의 `양어깨 높이 차이 / 화면상 어깨 거리`는 각각 화면상 기울기 각도의 사인입니다. 두 값에 `asin`을 각각 적용한 뒤 차이의 절댓값을 구합니다. 관측의 `shoulderTilt`는 v6부터 **라디안**입니다. 기준 자체가 조금 기울어져 있어도 기준 대비 각도를 비교하고, 좌우 방향은 같은 크기로 평가합니다. 카메라가 보는 2D 선의 각도이지 척추나 어깨의 해부학적 각도가 아닙니다.

| 설정 | 기본값 | 의미 |
| --- | --- | --- |
| `kneeDegrees` | 4° | 이 각도까지 추가 지수 감점 없음. 낮추면 가파른 감점이 더 일찍 시작 |
| `doublingDegrees` | 3° | 초과 각도의 지수 증가 간격. 작을수록 가파름. 반드시 양수 |
| `extraDeviation` | 0.08 | 지수 편차의 크기. 키우면 더 크게 감점, 0이면 지수 항만 제거 |

`a = 기준 대비 어깨 각도[도]`, `r = a × π/180`

`기울기 입력 = r + 0.08 × (2^(max(0, a-4)/3) - 1)`

`어깨 편차 = 0.7 × 기울기 입력 + 0.3 × 0.8 × 상하 변화`

편차 ≤0.04는 100점, ≥0.22는 0점, 사이는 선형 환산합니다. 각도를 입력으로 보면 4도부터 곡선이 가팔라지며 경계에서 점수가 불연속으로 튀지 않습니다.

| 기준 대비 화면상 어깨 각도 | 상하 변화가 0일 때 기본 점수(약) |
| --- | --- |
| 0~3° | 100점 |
| 4° | 95점 |
| 5° | 80점 |
| 6° | 63점 |
| 8° | 21점 |
| 10° | 0점 |
| 12° | 0점 |

목과 같은 움직임·2초 유예·점진 하락 보호를 거칩니다. 어깨에는 시간 추가 감점을 중복 적용하지 않았습니다. 각도만으로 0점까지 내려가므로 이번에는 비선형 감도의 효과를 먼저 확인합니다.

## UI·버전·검증

실제 상체 화면은 main의 카메라 → 기존 목/어깨/깜빡임 카드 → 추이 그래프 구조를 사용합니다. 로딩 경과·실제 오류 안내만 유지합니다. 추가했던 점수 근거 패널은 제품 화면에서 제외했고 개발용 `front/tests/posture-browser.html`에서만 사용합니다. 별도 데이터 검사실 `reports/posture-augmentation/model-inspector.html`도 그대로 사용할 수 있습니다.

점수 `upper-body-neck-v6-1fzxkw0` / `upper-body-shoulder-v6-9o3ijg`, 습관 `weighted-reference-deviation-v6[:s민감도]`. 이번 추가 조정은 산식 변경 없이 숫자를 바꿨으므로 v6 접두어를 유지하고 해시로 구분합니다. 숫자를 수정하면 점수 해시는 달라집니다. 어깨의 편차 정의가 바뀌어 습관 버전도 분리했습니다. API/DB 스키마는 유지하고 과거 기록은 보존합니다.

자동 검증은 시간 경계, 80점대/50점 아래 감소, 기준 범위/아주 작은 변화 제외, 모델 단독 제외, 움직임·누락·일시정지·공백, 복귀, 프레임 밀도, 평균/기록, 어깨 각도 경계·좌우·개인 기준을 확인합니다. 명령: `moti.cmd check`. 실제 사람의 정확도를 보장하는 검사는 아닙니다.

사용자 테스트 순서: 새 기준 수집 → 편한 자세/약간 기울임을 20초씩 → 머리만 충분히 전진한 채 10~20초 → 편한 자세로 복귀 → 어깨 작은/큰 기울임 → 가림/회전/재개. 불편함을 참으며 최대 범위를 유지할 필요는 없습니다. 체형·거리·기준 자세가 다른 여러 사람의 오감점과 복귀 지연을 보고 한 번에 한 설정씩 조절합니다.
