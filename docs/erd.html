Database ERD

Graduation Project · MySQL · server/schema.sql 기준 · 5개 테이블

PK Primary Key
FK Foreign Key
UQ Unique
IDX Index
──── : 1:N 관계 (CASCADE DELETE) - - - : 간접 FK (user_id 단축 참조)
👤 users
PK id INT AUTO_INCREMENT NOT NULL
UQ username VARCHAR(50) 로그인 ID, NOT NULL
nickname VARCHAR(100) 화면 표시 이름, NOT NULL
email VARCHAR(255) nullable
password_hash VARCHAR(255) bcrypt, NOT NULL
settings JSON nullable
created_at DATETIME DEFAULT NOW(), NOT NULL
⏱ sessions
PK id INT AUTO_INCREMENT NOT NULL
FK user_id INT → users.id CASCADE
mode VARCHAR(50) turtle/wrist/shoulder/eye
score INT DEFAULT 100
alert_count INT DEFAULT 0, NOT NULL
started_at DATETIME DEFAULT NOW(), NOT NULL
ended_at DATETIME nullable
📊 daily_statistics
PK id INT AUTO_INCREMENT NOT NULL
FK user_id INT → users.id CASCADE
UQ record_date DATE 복합 UQ (user_id, date, mode)
UQ mode VARCHAR(50) 복합 UQ, NOT NULL
total_monitoring_seconds INT 총 모니터링(초), DEFAULT 0
bad_posture_seconds INT 불량 자세(초), DEFAULT 0
average_score FLOAT 평균 점수
session_count INT DEFAULT 0, NOT NULL
💬 feedback
PK id INT AUTO_INCREMENT NOT NULL
FK user_id INT → users.id CASCADE
date DATE NOT NULL
mode VARCHAR(50) nullable
feedback_text TEXT nullable
created_at DATETIME DEFAULT NOW(), NOT NULL
📐 posture_logs
PK id INT AUTO_INCREMENT NOT NULL
FK session_id INT → sessions.id CASCADE
FK user_id INT → users.id CASCADE (단축 참조)
status ENUM GOOD / WARNING / DANGER
measured_value FLOAT 각도 또는 거리 값
IDX recorded_at DATETIME DEFAULT NOW(), INDEX
