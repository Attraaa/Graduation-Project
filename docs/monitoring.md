# 홈에서 시작하는 모니터링

2026-10-10 사용자가 승인한 듀얼 카드 구조입니다. 실행 모드는 **상체 / 키보드** 두 개이며, 상체의 목·어깨·깜빡임은 한 카메라의 같은 변환 영상을 사용합니다. 저장 부위/안구 계약과 기존 통계·학습이력은 보존합니다.

## 사용 흐름

- 홈 카드의 시작 버튼은 이동 없이 카메라와 분석을 시작합니다. 카드 오른쪽 위의 설정 아이콘은 그 모드의 카메라 설정 창을 엽니다. 모드별 상세 화면은 2026-11-21에 없앴으며 시작·일시정지·재개·중지는 홈 카드와 오버레이에서 합니다.
- 홈 카드의 미리보기 외곽은 16:9를 유지합니다. 카메라 원본 비율은 여백 안에 맞춰 표시하며 분석 영상 크기는 바꾸지 않습니다. 준비·보정·관찰·일시정지·오류 안내는 공통 고정 높이 영역에 표시하고 긴 안내는 그 안에서 스크롤합니다.
- 시작 / 일시정지·재개 / 중지는 항상 별도 슬롯에 남습니다. 실행 중에는 시작을, 정지 중에는 일시정지·중지를 비활성화합니다. 상체의 **기준 다시 잡기**와 키보드의 **위치 다시 잡기**는 카메라 설정 창의 모드·카메라 선택 아래에 있으며 그 모드가 실행 중이고 일시정지가 아닐 때만 활성화합니다. 시작 더블클릭으로 같은 좌표의 중지를 누르는 일이 없으며 중지에 대기 제한을 두지 않습니다.
- 상체와 키보드는 각각 다른 장치를 선택해 동시에 실행할 수 있습니다. 카메라 설정 창의 **모드 / 사용할 카메라**에서 연결을 정합니다. 선택은 `moti.camera-device.<modeId>`에 저장하고 다음 실행 때 복원합니다. 장치를 바꿀 때는 해당 모드만 중지합니다.
- 설정 창을 열거나 장치를 선택해도 카메라를 자동으로 켜지 않습니다. 영상 변환/키보드 영역 조정은 기존 장치별 자동 저장 계약을 사용합니다.
- 일시정지는 마지막 화면·현재 지표·세션 평균을 유지하고, 영상 분석과 키 입력 관찰을 멈춥니다. 트랙은 유지하지만 영상 갱신은 멈춥니다. 재개 때 기존 기준과 누적을 이어가며 중지할 때 트랙·모델·분석기를 해제합니다.
- 화면의 활성 시간은 일시정지를 제외합니다. 기존 저장 계약의 `runMs`는 세션의 전체 경과 시간이며 일시정지 중에는 유효 관찰 시간이나 점수를 더하지 않습니다.
- 측정이 끝나 마지막 배치가 서버에 저장되면 열려 있는 홈·통계·학습이력이 기록을 다시 불러옵니다. 새 값이 올 때까지 이전 값을 그대로 보여 주며, 한 세션의 목·어깨·안구 저장은 한 번의 재조회로 묶습니다. 측정 중의 중간 저장으로는 다시 불러오지 않습니다.
- 페이지 이동은 측정을 유지합니다. 로그아웃은 측정을 멈추고 현재 로그인으로 마지막 배치를 저장한 뒤 로그인 정보를 지웁니다(`authStore.logoutAfterSaving`). 저장에 실패하면 취소하거나 미저장 기록을 버리고 로그아웃할지 묻습니다. 그 밖의 앱 영역 이탈은 런타임을 해제하고 종료 배치를 전송합니다. 잠금·절전은 전체 측정과 설정 창을 멈춥니다. 즉시 중지 단축키는 사용자 요청으로 제거했으며 화면에서 각 모드를 일시정지/중지합니다.
- 승인 앱은 키보드 시작 때 설정 목록에 따라 관찰합니다. 별도 시작 체크박스가 없습니다. 목록이 비어 있으면 Moti의 화면 입력만 관찰하며 시작을 막지 않습니다. 목록 밖/관리자/권한 확인 불가 앱을 제외하는 기존 경계는 유지합니다.
- 안구 v3 보정은 상체 시작 후 열린 눈·얼굴 기준 3초와 양안 깜빡임 3회로 수집합니다. 홈 상체 카드는 보정 중에만 짧은 안내와 진행률을 표시하며 보정 동작은 실제 횟수·유효 시간에서 제외합니다. 상체의 기준 다시 잡기는 안구 기준도 다시 모으되 안구 누적 기록은 유지합니다.
- 깜빡임 민감도(기본 보통)와 자세 무너짐 민감도(기본 50%)는 설정 화면에서 고릅니다. `MonitoringProvider`가 상체 시작 때 두 값을 읽어 그 실행 동안 고정하고, 분석기와 기록기에 같은 값을 전달합니다. 바꾼 값은 다음 상체 시작부터 적용됩니다. 개인 눈 기준은 세션 메모리에만 유지합니다.

## Windows 자세 경고 알림

설정의 **Windows 알림**은 자세·키보드·깜빡임 경고와 카메라·분석·저장·세션 만료 문제를 안내합니다. 자동 알림은 설정이 ON이고, 아직 유효한 사유가 있으며, **다른 앱을 보거나 오버레이 모드일 때** 보냅니다. 일반 모드에서 본창·카메라 설정 창에 포커스가 있으면 보내지 않습니다. 수동 **알림 테스트**만 포커스 조건의 예외이며 카메라 없이 사용할 수 있습니다. 브라우저 시연에서는 지원하지 않습니다. Windows의 알림 허용·배너·방해 금지 설정이 최종 표시와 소리를 결정합니다.

- 목 또는 어깨의 현재 점수가 **경고 점수 기준 이하로 유효 관찰 3초** 이어지면 경고합니다(기본 70점). 세션 평균을 사용하지 않습니다.
- 기존 `deviationState === 'away'` 판정도 알림 조건입니다. 이는 설정 민감도로 정해지는 지속된 기준 이탈이며, 점수 저하와 독립적입니다. 기존 점수·습관 정책과 저장 기록은 바꾸지 않습니다.
- 목·어깨가 동시에 조건을 충족하면 한 알림에 묶습니다. 보정·관찰 불가·점수 누락·움직임/감점 유예/복귀 확인 중에는 해당 부위의 경고를 보류하고 저점수 확인 시간을 새로 셉니다. 일시정지·중지·알림 끄기·로그아웃은 알림을 정리합니다. 재개·새 실행·기준 재수집 뒤에는 새 관측을 기다립니다.
- 첫 경고는 조건이 확정되는 시점에 보냅니다. **반복 알림 간격**의 5/10/30분은 첫 경고 이후의 최소 간격입니다(기본 10분). **발생 시**는 조건이 이어지는 구간에서 한 번만 보내며 회복 후 다시 경고할 수 있습니다. 짧은 회복·재이탈에서도 최소 10초 간격을 둡니다.
- 키보드는 **최근 20회 유효 판정의 평균 훈련 점수가 70점 이하**일 때 알립니다. 기존 100·70·0 훈련 점수를 그대로 쓰며 판정 불가는 분모에서 제외합니다. 입력 이벤트마다 마지막 20개의 점수와 중복 방지 ID만 메모리에서 관리하고 입력 원문은 보관하지 않습니다. 20회 미만·미승인 앱 제외·준비/맵 재인식·오류·일시정지·OFF는 알리지 않으며 해당 구간 전의 창을 비웁니다. 동일 실행의 이전 입력 ID는 다시 세지 않습니다. 최근 유효 입력이 2초보다 오래됐으면 발송하지 않고 새 유효 입력을 기다립니다. 자세의 경고 점수 슬라이더는 키보드의 고정 70점 기준을 바꾸지 않습니다.
- 깜빡임은 기존 분석기의 `openReminder`, 즉 **개인 보정 후 눈을 뜬 채 유효 관찰 15초 동안 깜빡임이 없음**을 사용합니다. 분당 빈도나 단순 실행 15초로 판단하지 않습니다. 깜빡임·관찰 유실·긴 프레임 공백·보정·일시정지·OFF는 경고 구간을 끊습니다. 2초 이내의 새 분석 갱신이 있어야 발송하며 상체 재시작·기준 재수집 때 이전 알림을 초기화합니다.
- 자세·키보드·깜빡임은 ON/OFF·소리·반복 간격을 공유하지만 사건과 마지막 발송 시각은 각각 관리합니다. 한 종류의 경고가 다른 종류의 첫 경고를 소비하지 않습니다. 클릭하면 홈을 열고 키보드 경고는 키보드 카드, 자세·깜빡임 경고는 상체 카드로 이동합니다(분석·추적 문제 알림도 같은 모드 카드, 저장 문제는 저장 안내). 위 기준은 안내용 제품 설정이며 건강·질병·오타 판정이 아닙니다.
- 알림 켜기·반복 간격·소리·경고 점수는 변경 즉시 적용합니다. 기존 ‘알림 세기’는 OS가 지원하는 **알림 소리 켜기/끄기**로 연결했습니다. 기존 `soft`는 무음, `normal`/`strong`은 기본 소리로 읽습니다. 측정 민감도는 계속 다음 실행부터 적용합니다.

`features/notifications/postureAlerts.ts`는 자세 조건을, `usePostureNotifications.ts`는 공통 런타임 연결과 전달 결과를 소유합니다. 포커스로 생략한 경고는 발송 주기를 소비하지 않으며, 이후에도 신선한 관측에서 조건이 유지될 때 보냅니다. 이전 실행·회복 후의 늦은 전달 응답은 새 사건에 적용하지 않습니다. Electron main은 신뢰 주 창·프레임·URL과 요청을 검사하고 표시 직전에 설정·포커스·전원 상태를 재확인합니다.

`activityPolicy.ts`는 승인된 키보드 알림 상수를, `activityAlerts.ts`는 키보드/깜빡임 조건과 전달 ACK를, `useActivityNotifications.ts`는 입력별 관찰·수명주기·제한된 재시도를 소유합니다. 측정 산식·보정·저장 정책은 변경하지 않습니다.

카메라·상체/키보드 분석의 치명적 실패는 **해당 모드를 오류로 중지**하고 활성 시간을 멈추며 기존 자원 해제·종료 기록 경로를 사용합니다. 다른 모드는 유지합니다. 깜빡임만 실패하면 해당 분석/기록을 끝내고 상체 자세 관찰은 유지합니다. 상체 관측 불가는 10초 지속 시 한 번 알리고, 정상 관찰 3초 뒤 재발에 다시 허용합니다. 이는 의료적 기준이 아닌 안내 정책입니다. 키보드의 미승인 앱 제외·입력 없음은 장애로 알리지 않습니다.

운영 오류는 자세 경고 주기와 별도 사건으로 관리합니다. 저장 실패는 2초 지속 후 한 번 안내하고 복구되면 해제합니다. 세션 만료는 로그인 화면 전환 뒤에도 한 번 안내합니다. OFF는 모든 자동 Windows 알림을 막지만 화면 오류는 유지합니다. 실패 전달은 제한적으로 재시도하며 앱/오버레이에 확인 안내를 남깁니다. 잠금·절전은 측정을 중지하고 자동 알림을 막으며, 해제 후 자동 시작하지 않습니다. 알림 클릭은 본창을 복원해 홈의 해당 모드 카드·저장 영역·로그인을 열고 측정을 시작하지 않습니다.

## 작은 오버레이

사이드바 **오버레이**로 340×118 DIP의 독립된 미니 바 창을 엽니다. 본창의 카메라 설정 창을 닫고 작은 창의 초기 상태 표시를 확인한 뒤 본창을 최소화합니다. 창 생성에 실패하면 본창을 유지합니다. 작은 창은 항상 위에 표시하고 버튼을 뺀 어느 곳이든 끌어서 옮길 수 있으며 마지막 위치를 기억합니다. 모니터 작업 영역에 위치를 보정합니다.

상체·키보드를 한 줄씩 표시합니다. 각 줄은 모드 색 막대, 큰 숫자, 보조 값, 상태 칩, 활성 시간, 시작·일시정지·재개를 겸하는 버튼 하나와 중지 버튼으로 이루어집니다. 큰 숫자는 상체가 목·어깨 현재 점수, 키보드가 세션 평균 점수이고 보조 값은 깜빡임 빈도와 판정한 입력 수입니다. 화면에 보이는 정수가 경고 점수 이하이면 숫자를 빨간색으로 표시합니다. 목·어깨는 설정의 경고 점수(기본 70점), 키보드는 키보드 알림 기준 70점을 씁니다. 기준 자세 수집·관찰 불가·오류·미승인 앱일 때는 숫자 대신 두 줄 안내를 표시하고, 저장 실패·연결 확인·명령 실패 안내는 위쪽 띠에 표시합니다. 시간은 일시정지를 제외한 기존 세션 시간이며 전환으로 초기화하지 않습니다. 기준 재수집·장치 변경·미리보기·그래프는 본창에서 사용합니다. 요약은 약 1초마다, 중요한 상태 변화는 즉시 갱신합니다. 4초 이상 본창 요약이 없으면 연결 확인을 표시하고 시작·일시정지를 막습니다. 중지와 복귀는 남깁니다.

위쪽 띠의 **돌아가기**(↗) 버튼으로 기존 페이지·창 크기·최대화 상태를 복원합니다. X 버튼은 없습니다. Alt+F4, 작업 표시줄의 본창 복원, 알림 클릭도 같은 복귀 경로를 사용합니다. 전환·복귀는 측정을 중지하거나 새로 시작하지 않습니다. 실제 앱 종료는 본창의 기존 저장·실패 확인 흐름을 사용합니다.

본창의 `MonitoringProvider`가 카메라·추론·Python·기록을 계속 소유합니다. 작은 창은 새 분석기를 열지 않고 제한된 요약/명령만 주고받습니다. 명령 ID·실행 ID·소유자 검증과 응답 확인으로 중복·이전 실행의 명령을 막습니다. JWT·기록 API·키보드 서비스 권한은 작은 창에 노출하지 않습니다. 승인 앱 입력 범위도 유지하며 작은 창의 조작 키를 본창 학습 입력으로 전달하지 않습니다. 앱 종료 뒤 상주·트레이·자동 시작은 추가하지 않았습니다.

Windows 최소화에서 RAF가 느려지는 환경을 위해 네이티브 앱의 카메라 변환·자세/안구 분석은 취소 가능한 타이머로 예약합니다. 새 영상인지와 단일 추론 여부를 기존 모듈에서 확인하며 캡처 시각·500ms 관측 공백·점수/저장 규칙은 유지합니다. 브라우저 시연은 기존 RAF와 화면 이탈 보류를 유지합니다.

설치 앱은 NSIS 시작 메뉴 바로가기와 `com.graduation.moti` 식별자를 사용합니다. 개발 앱은 설치본과 구분되는 `com.graduation.moti.development` 식별자와 사용자 시작 메뉴의 `Moti (개발).lnk`를 등록합니다. 개발 알림을 위한 바로가기는 해당 체크아웃을 가리킵니다.

## 지표와 그래프

대시보드의 상체 지표는 기존 카드 크기로 목 점수·어깨 점수·깜빡임 빈도를 나란히 표시합니다. 목·어깨는 유효 시간 가중 세션 평균, 깜빡임은 누적 유효 시간 기준 빈도를 사용합니다. 빈도는 기존 정책대로 유효 관찰 30초 전에는 `—`이며 안구 점수는 만들지 않습니다. 휴식 버튼·별도 안구 탭·모드 옵션은 없습니다.

2026-11-14 UI 정리에서 상세의 카메라 설정·기준/위치 다시 잡기는 상단에, 시작·일시정지/재개·중지는 카메라 하단의 고정 슬롯에 배치했습니다(이 상세 화면은 2026-11-21에 없앴습니다). 짧은 창은 미리보기 표시 폭을 줄여 첫 화면에서 제어할 수 있게 하며, 분석 영상 해상도와 16:9 외곽은 유지합니다. 오버레이는 모드별 오른쪽 아이콘 제어와 하단 복귀를 사용했으며, 2026-11-21에 위의 미니 바로 바꿨습니다. 모드별 명령·준비 확인·오류·저장·측정 규칙은 바꾸지 않았습니다. [UI 변경·전체 재검토](reviews/2026-11-14-ui-and-functional-review.md)에 실제 검사와 남은 문제를 기록했습니다.

실시간 그래프는 2026-11-21부터 홈(학습) 화면의 각 카드 아래에 있습니다. 상체 그래프는 목·어깨 두 선, 키보드 그래프는 판정한 입력의 100/70/0 값을 표시합니다. 최근 5분의 표시용 메모리이며 새 실행 때 지웁니다. 누락·일시정지·판정 보류·입력이 없는 구간에는 점수를 만들거나 선을 연결하지 않습니다. 홈에 있던 7일 그래프·오늘 타임라인·기준 이탈이 잦은 시간은 지웠거나 옮겼습니다. 지난 점수는 통계의 날짜별·시간대별 점수, 기준 이탈이 잦은 시간은 통계 상체 탭(7/30일 선택을 따름), 그날의 기록은 오늘 날짜로 열리는 학습이력에서 봅니다. 실시간 입력 순서/영상/그래프 표본을 서버에 새로 저장하지 않습니다.

키보드는 현재 입력 점수와 전체 세션 평균을 구분하고, 판정 가능 비율·판정한 입력·일관성을 표시합니다. 최근 입력은 최대 5행과 고정된 열로 표시하며 긴 판정 이유는 말줄임/툴팁으로 제공합니다.

## 책임과 검증

`AppLayout → MonitoringProvider`가 두 세션의 런타임을 유지합니다. 홈 카드(`features/dashboard/ModeCards.tsx`)가 화면이며 `MonitoringPreview`는 기존 캔버스를 복사하므로 화면 이동/설정 창으로 추가 스트림을 만들지 않습니다. `PostureMonitor`는 자세 카메라를 소유하고 `EyeMonitor(shared)`는 그 스트림을 빌립니다. `KeyboardMonitor`는 손캠·로컬 분석기·입력 관찰을 소유합니다. 점수·관측·서버 저장 계약은 기존 모듈을 사용합니다. 예전 상세 주소(`/learn/...`, `/learn/eye` 포함)는 홈으로 연결합니다.

자동 검사와 가상 카메라/분석 대역의 결과는 [development.md](development.md)를 확인합니다. 실물 카메라 두 대의 드라이버 호환성, 장시간 동시 추론 성능과 실제 인식 정확도는 별도 촬영 검증 대상입니다.
