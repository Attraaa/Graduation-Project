# 홈에서 시작하는 모니터링

2026-10-10 사용자가 승인한 듀얼 카드 구조입니다. 실행 모드는 **상체 / 키보드** 두 개이며, 상체의 목·어깨·깜빡임은 한 카메라의 같은 변환 영상을 사용합니다. 저장 부위/안구 계약과 기존 통계·학습이력은 보존합니다.

## 사용 흐름

- 홈 카드의 시작 버튼은 이동 없이 카메라와 분석을 시작합니다. 옆의 설정 아이콘으로 상세 모니터링 화면을 엽니다. 상세 화면에서도 시작·일시정지·재개·중지할 수 있습니다.
- 상체와 키보드는 각각 다른 장치를 선택해 동시에 실행할 수 있습니다. 카메라 설정 창의 **모드 / 사용할 카메라**에서 연결을 정합니다. 선택은 `moti.camera-device.<modeId>`에 저장하고 다음 실행 때 복원합니다. 장치를 바꿀 때는 해당 모드만 중지합니다.
- 설정 창을 열거나 장치를 선택해도 카메라를 자동으로 켜지 않습니다. 영상 변환/키보드 영역 조정은 기존 장치별 자동 저장 계약을 사용합니다.
- 일시정지는 마지막 화면·현재 지표·세션 평균을 유지하고, 영상 분석과 키 입력 관찰을 멈춥니다. 트랙은 유지하지만 영상 갱신은 멈춥니다. 재개 때 기존 기준과 누적을 이어가며 중지할 때 트랙·모델·분석기를 해제합니다.
- 화면의 활성 시간은 일시정지를 제외합니다. 기존 저장 계약의 `runMs`는 세션의 전체 경과 시간이며 일시정지 중에는 유효 관찰 시간이나 점수를 더하지 않습니다.
- 페이지 이동은 측정을 유지합니다. 로그아웃/앱 영역 이탈은 런타임을 해제하고 종료 배치를 전송합니다. 잠금·절전은 전체 측정과 설정 창을 멈춥니다. 즉시 중지 단축키는 사용자 요청으로 제거했으며 화면에서 각 모드를 일시정지/중지합니다.
- 승인 앱은 키보드 시작 때 설정 목록에 따라 관찰합니다. 별도 시작 체크박스가 없습니다. 목록이 비어 있으면 Moti의 화면 입력만 관찰하며 시작을 막지 않습니다. 목록 밖/관리자/권한 확인 불가 앱을 제외하는 기존 경계는 유지합니다.
- 안구 v3 보정은 상체 시작 후 열린 눈·얼굴 기준 3초와 양안 깜빡임 3회로 수집합니다. 홈/상체 상세는 보정 중에만 짧은 안내와 진행률을 표시하며 보정 동작은 실제 횟수·유효 시간에서 제외합니다. 상체의 기준 다시 잡기는 안구 기준도 다시 모으되 안구 누적 기록은 유지합니다.
- 민감도는 `MonitoringProvider`의 보통 값으로 고정하고 분석기와 기록기에 같은 값을 전달합니다. 낮음·높음 계산과 `EyeCalibrationPanel`은 추후 설정 연결용으로 보존하며 현재 선택 UI는 없습니다. 설정 연결 시 세션 시작에 값을 고정하고 측정·기록에 함께 적용합니다. 개인 눈 기준은 세션 메모리에만 유지합니다.

## 지표와 그래프

상체는 기존 지표 카드 크기로 목 점수·어깨 점수·깜빡임 빈도를 나란히 표시합니다. 각 카드 아래에 목·어깨의 유효 시간 가중 세션 평균과 누적 유효 시간 기준 깜빡임 빈도를 표시합니다. 빈도는 기존 정책대로 유효 관찰 30초 전에는 `—`이며 안구 점수는 만들지 않습니다. 휴식 버튼·별도 안구 탭·모드 옵션은 없습니다.

상체 실시간 그래프는 목·어깨 두 선, 키보드는 판정한 입력의 100/70/0 값을 표시합니다. 최근 5분의 표시용 메모리이며 새 실행 때 지웁니다. 누락·일시정지·판정 보류·입력이 없는 구간에는 점수를 만들거나 선을 연결하지 않습니다. 홈의 7일 그래프는 기존 서버 기록으로 목·어깨·키보드를 표시합니다. 실시간 입력 순서/영상/그래프 표본을 서버에 새로 저장하지 않습니다.

키보드는 현재 입력 점수와 전체 세션 평균을 구분하고, 판정 가능 비율·판정한 입력·일관성을 표시합니다. 최근 입력은 최대 5행과 고정된 열로 표시하며 긴 판정 이유는 말줄임/툴팁으로 제공합니다.

## 책임과 검증

`AppLayout → MonitoringProvider`가 두 세션의 런타임을 유지합니다. `PostureSession`/`KeyboardSession`은 화면이며 `MonitoringPreview`는 기존 캔버스를 복사하므로 화면 이동/설정 창으로 추가 스트림을 만들지 않습니다. `PostureMonitor`는 자세 카메라를 소유하고 `EyeMonitor(shared)`는 그 스트림을 빌립니다. `KeyboardMonitor`는 손캠·로컬 분석기·입력 관찰을 소유합니다. 점수·관측·서버 저장 계약은 기존 모듈을 사용합니다. `/learn/eye`는 상체 상세로 연결합니다.

자동 검사와 가상 카메라/분석 대역의 결과는 [development.md](development.md)를 확인합니다. 실물 카메라 두 대의 드라이버 호환성, 장시간 동시 추론 성능과 실제 인식 정확도는 별도 촬영 검증 대상입니다.
