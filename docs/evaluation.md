# 점수와 습관 평가 검증

2026-10-02 현재 **단일 상체 모드의 목·어깨 독립 점수와 관찰 습관 집계**를 구현했습니다. 아래 수치는 개발용 제품 설정이며 실험으로 검증한 건강 기준이 아닙니다. 키보드 분석은 기존 독립 화면을 유지합니다.

## 점수 알고리즘 v2

| 부위 | 가중 편차 `d` | 정책 버전 |
| --- | --- | --- |
| 목 | `0.35 × headForward + 0.25 × torsoForward + 0.4 × neckSlump` | `upper-body-neck-v2-<설정 해시>` |
| 어깨 | `0.7 × shoulderTilt + 0.3 × shoulderShrug` | `upper-body-shoulder-v2-<설정 해시>` |

사용자 요청으로 [통합 설계](posture_score_analysis_and_design.md)를 적용했습니다. 화면은 `upper_body` 하나이며 두 부위 점수를 병렬 표시합니다. 종합 점수는 만들지 않습니다. 저장 계약의 `turtle`/`shoulder`는 기존 데이터를 보존하기 위한 부위 키입니다.

머리 전진은 귀 수평 폭의 기준 대비 증가율, 상체 전진은 어깨 픽셀 거리의 기준 대비 증가율입니다. 감소는 0으로 제한합니다. 목 처짐과 어깨 으쓱임에는 `(기준 귀-어깨 높이 − 현재 높이) / 기준 어깨 폭`의 양수 부분을 같이 사용합니다. 정면 영상만으로 두 원인을 구별하거나 근육 긴장을 확정할 수 없습니다. 어깨 기울기는 `현재 양어깨 높이 차이 절댓값 / 현재 어깨 폭`이며 기준 기울기를 빼지 않습니다. 코는 yaw 계산에만 사용합니다. `yawRatio > 0.15`이면 머리 전진 항만 0으로 처리하며 다른 가중치를 재분배하지 않습니다.

현재 `dev/score2` 조정값은 목 편차 0.04 이하 100점, 0.20 이상 0점, 어깨 편차 0.03 이하 100점, 0.18 이상 0점이며 사이는 선형 환산합니다. 편차는 무차원 비율의 가중합이며 각도나 cm가 아닙니다. 반올림은 표시할 때만 합니다.

조정 위치는 [scoreSettings.ts](../front/src/features/posture/scoreSettings.ts) 맨 위 상수입니다. 각 부위의 가중치 합은 1로 유지합니다(자동 정규화 없음). 값을 바꾸고 새 측정을 시작하면 됩니다. 설정 해시를 점수 정책 ID에 포함하므로 가중치·임계값·움직임 보호 설정이 다른 기록은 서로 평균하거나 전일 비교하지 않습니다. 공식 자체를 바꿀 때는 버전도 올립니다.

### 움직임 보호와 평균

- 귀·어깨 4점 중 하나라도 캡처 간 속도가 **250px/초 초과**이면 이전 표시 점수를 동결합니다. 속도는 유효한 연속 관측 사이에서만 계산하며 동결의 최대 유지 시간은 따로 두지 않습니다.
- 움직임 중에는 유예 타이머를 초기화합니다. 멈춘 첫 이탈 관측부터 **2초**를 세고, 초과한 뒤 **초당 35점** 한도로 원점수까지 감소합니다. 허용 범위로 복귀하면 100점으로 회복합니다. 두 부위 타이머는 독립입니다.
- 첫 유효 관측에 이전 점수가 없으면 100점에서 유예를 시작합니다. 가림·저신뢰도·중복/역행 시각은 동결된 값으로 채우지 않고 `null`로 표시하며 시간을 더하지 않습니다.
- 평균과 SQLite에는 보호를 적용한 표시 점수를 유효 시간으로 사다리꼴 적분합니다: `Σ((이전 점수 + 현재 점수) / 2 × 유효 간격) / Σ유효 간격`. 보호 중 관측 가능한 시간도 분모에 포함하고 500ms를 넘는 공백은 제외합니다. 감점 시작과 분 경계는 프레임 간 선형 보간 근사입니다. 분모가 없으면 평균은 `null`, 실제 최저 점수는 `0`입니다.

이 초기값들은 실제 웹캠으로 조정할 제품 설정입니다. 픽셀 속도는 해상도의 영향을 받습니다. 원 편차와 보호 상태는 함께 표시하며, 습관 지표는 점수 보호와 별도로 집계합니다.

## 점수와 분리된 습관 정보

- 관측률: 유효 관찰 시간 / 실행 시간. 실행 시간에는 모델 준비와 기준 수집이 포함됩니다. 분모 0은 `—`이며 미확인 시간을 휴식으로 바꾸지 않습니다.
- 연속·최장 관찰: 유효한 연속 구간 길이. 누락이나 긴 공백에서 현재 연속 구간을 끊습니다. 실제 작업·착석 시간을 확정하지 않습니다.
- 지속된 기준 이탈: `weighted-reference-deviation-v2` 정책입니다. 부위별 가중 편차를 사용하고 움직임 구간은 이탈 연속성을 끊습니다. `d ≥ 0.15`인 양 끝 관측 구간이 2,000ms 이상 연속되면 1회로 확정합니다. 이후 `d ≤ 0.10`이면 종료합니다. 진입과 복귀 기준을 달리해 경계 주변 흔들림에 반복 집계되는 것을 줄입니다.
- 확정 후 이탈 시간: 확정된 이탈 상태가 양 끝에서 이어진 유효 간격만 더합니다. 대기 2초는 소급 가산하지 않습니다. 누락·새 기준·중지는 구간을 종료하며, 확인하지 못한 복귀나 휴식을 만들어내지 않습니다.

15%·10%·2초도 잠정 제품 설정입니다. 이 지표는 기준에서 달라진 구간의 기록이며 잘못된 자세·오사용·자세 전환 빈도·휴식 판정과 다릅니다. 이를 하나의 습관 점수로 합치거나 오래 같은 자세라는 이유로 자세 점수를 깎지 않습니다. 명시적 휴식 기록·휴식 알림은 후속 작업입니다.

## 관측값의 의미

- `delta`는 귀·어깨의 **화면상 변화 비율과 현재 기울기**입니다. 증가/감소의 한쪽만 사용하는 항은 반대 방향 변화도 0이므로, 0이 반드시 기준과 동일함을 뜻하지 않습니다. 100점은 허용 범위 또는 움직임·유예 보호를 반영한 값이며 건강한 자세, 해부학적 정상, 거북목 진단을 뜻하지 않습니다. 기준 수집·관측 모듈 자체는 점수를 계산하지 않습니다.
- 관측 누락·낮은 가시성은 `delta: null`입니다. 정상 자세, 오사용 또는 휴식으로 분류하지 않습니다. 화면 갱신 간격 중 누락이 발생해도 이전 변화량은 즉시 지웁니다.
- `observedSeconds`는 기준 확보 후 연속된 유효 관측 사이의 시간 합입니다. 첫 관측과 재개 첫 관측은 시간을 더하지 않으며 기준 수집 시간도 제외합니다. PC 작업시간·실제 착석시간·휴식시간의 측정값이 아닙니다.
- 시간은 프레임 캡처 시점의 단조 증가 시각을 사용합니다. 500ms까지의 연속 간격만 가산하고, 초과 간격 전체를 제외합니다. 중복·역행·비유한 시각은 값을 지우고 연속성을 끊습니다. 역행 이전의 마지막 시각을 유지해 같은 구간을 다시 더하지 않습니다.

구현은 [observation.ts](../front/src/features/posture/observation.ts), 수집 설정은 [calibration.md](calibration.md)를 따릅니다. 500ms·가시성 0.7 등의 값은 기존 수집 설정이며 건강·점수·습관 판정 임계값이 아닙니다.

`PostureMonitor`는 모든 관측 결과를 점수·습관 계산에 전달한 뒤 화면만 약 200ms 간격으로 갱신합니다. 중지 시 마지막 계산을 화면에 반영하고, 새 세션이나 모드 변경에는 이전 결과를 전달하지 않습니다. 정책 버전이 바뀌면 평균·습관 누적을 초기화해 서로 다른 정책 결과가 섞이지 않게 합니다. 현재 결과의 버전은 `MonitorSnapshot.neck`/`shoulder`와 SQLite 부위별 기록에 저장합니다.

## 자동 검증과 수정 결과

| 대상 | 확인한 동작 |
| --- | --- |
| 상체 계산 | 같은 입력 재생 시 같은 상태·변화량·점수·관찰 시간, 입력 불변성, 기준 수집 시간 제외, 모드별 사용 지표 격리 |
| 누락·재개 | 누락·저신뢰도에서 `null`, 누락 구간 제외, 재개 첫 프레임 미가산, 카메라/기준 변경 시 구간 분리 |

| 새 점수·습관 | 목 8%/30%·어깨 5%/25% 경계, 가중치·회전 방어·움직임 동결·5초 유예·점진 감점, 15% 진입·10% 복귀·2초 경계, 시간 가중 평균, 프레임 밀도, 누락·정책 변경 초기화 |
| 기존 점수 입력 | 0·100 포함, 누락·범위 밖·소수·문자열 거부. 로그의 누락 측정값과 실제 0 구분 |
| 서버 평균 | 오늘·달력 모두 세션 수 가중 평균. 평균값이 `null`인 행은 점수 분모에서 제외하고 실제 0점은 포함. 점수 자료가 없으면 `null` |
| 날짜별 조회 | 달력 날짜 구분, 다일 세션에서 다른 날짜의 같은 시각 로그를 별도 분으로 그룹화 |

달력의 기존 단순 평균 오류를 수정했습니다. 예를 들어 90점 9세션과 0점 1세션은 45점이 아니라 81점입니다. 평균은 최종 결과에서 반올림합니다. `sessionCount`에는 점수 없는 행의 세션도 포함합니다. 기존 집계 행 내부에서 누락된 개별 점수 수는 현재 스키마로 복원할 수 없습니다.

실행: `moti.cmd check`와 프론트 `npm run build`. 최신 검사 수와 화면 검증 결과는 [development.md](development.md)에 기록합니다. 이 테스트들은 실제 카메라의 판별 정확도를 검증하지 않습니다.

## 자정 집계의 현재 계약과 한계

기존 서버는 DB의 `DATE(started_at)`에 세션 전체 시간을 귀속합니다. 예를 들어 9월 12일 23:59:50에 시작해 13일 00:00:10에 종료한 세션은 **12일에 20초와 세션 1회**로 집계하는 SQL입니다. 날짜별로 10초씩 분할하지 않습니다. 이는 유지한 기존 계약이며 새 습관 통계 정책이 아닙니다.

새 상체 점수·습관 계산은 단조 시각을 사용하므로 자정에 평균이나 이탈 대기 시간이 초기화되지 않습니다. 기존 서버에는 새 정책의 결과를 아직 전송하지 않습니다. 시간 가중 점수·관측률·정책 버전의 일별 저장은 기존 세션 수 평균과 구분해 데이터 계약을 정한 뒤 연결해야 합니다.

테스트는 SQL·트랜잭션 대역과 날짜가 지정된 응답 자료를 검사합니다. **실제 DB에서 자정 경계를 실행한 검증은 아닙니다.** MySQL 드라이버의 `timezone: '+09:00'`만으로 DB 세션 시간대가 설정되었다고 볼 수 없습니다. 실제 DB 선정 후 DB 시간대, SQL mode, FLOAT 누적 정밀도, 동시 종료 및 월말·연말 경계를 확인해야 합니다. 세션 시작 응답의 JS 시각과 DB 저장 시각의 차이도 확인 대상입니다.

세션 상세 그래프는 날짜까지 포함해 그룹화하지만 응답의 `time`은 기존 `HH:mm`입니다. 다일 세션에는 같은 라벨이 여러 번 나올 수 있습니다. 그래프의 `AVG(measured_value) AS score` 역시 단위가 미정인 기존 필드이며 새 자세 점수가 아닙니다.

## 남은 평가

- 실제 영상에서의 인식률·구도 재현성·측정 정확도와 화면 상태 전환 확인
- 실제 촬영 자료에 근거한 v2 가중치·속도·유예·습관 설정 조정, 자세 변화·명시적 휴식 이벤트 정의
- 대상 DB에서의 실제 자정 실행과 날짜별 시간 분할 필요 여부
- 앱의 실제 저장 연결 이후 같은 계정의 저장·재조회 통합 검사

로그인은 로컬 데모입니다. 2026-09-19부터 목·어깨 통계와 학습이력은 별도 SQLite 경로의 실측 기록을 조회합니다. 위 기존 서버 집계와 연결하지 않으며 아래 로컬 집계 계약을 적용합니다.

모드와 기능을 나눠 맡는 방법은 [협업 안내](collaboration.md)를 따릅니다.

## 로컬 SQLite 집계 계약 (2026-09-19)

키보드의 2026-10-01 정책은 [키보드 계약](../front/src/features/keyboard/README.md)을 따릅니다. 기본표·허용 100, 같은 손 인접 70, 그 외 0을 판정 가능한 입력 수로 평균하고 보류는 분모에서 제외합니다. 판정 가능 비율과 사용 일관성은 분리하며 정책/인식 버전/가중치가 다른 기록은 합산하지 않습니다. 일관성은 키·Shift 상황별 10회 이상 그룹의 최빈 손가락 수/그룹 관측 수이며 점수 보너스가 아닙니다. 타자 내용의 오타율·건강 개선율·판별 정확도로 읽으면 안 됩니다.

가림 자체를 감지하는 모델은 없으며 손끝 관측 부족, 키보드/손 구분 품질, 거리·후보 차이와 프레임 시간 차이를 잠정 보류 기준으로 사용합니다. MediaPipe의 손 구분 점수는 손끝 정확도 확률이 아닙니다. 70점과 기하 임계값은 CHI 2016이 검증한 수치가 아닙니다. 자동 검사는 산식·데이터 보존·상태·보안 경계만 검증하고 실제 카메라의 인식률은 검증하지 않습니다.

목·어깨의 기존 evaluation 누적 결과를 화면 갱신 전 모든 캡처에서 기록합니다. 500ms 이하 유효 구간의 사다리꼴 점수 적분을 분 경계에 나누고 같은 모드·정책의 유효 시간 합으로 평균합니다. 미관측 시간과 0점은 구별하며 원시 프레임은 저장하지 않습니다. 통계 날짜는 구간 발생일, 이력 날짜는 기록 시작일입니다. 시간대는 기록 시작 offset을 유지합니다. 전일 차이는 같은 정책의 점수 차이이며 의료적 개선율이 아닙니다. 최장 연속 관찰은 날짜에 포함된 기록 전체의 최댓값으로 명시합니다.

`record-replay.test.mjs`는 실제 observation/evaluation reducer에 누락·중복·역행 프레임을 넣어 저장된 시간·적분·기준 이탈·최장 관찰 합계가 동일함을 확인합니다. 파일 SQLite 재시작/잠금/롤백/세대 삭제, 자정·연말·정책 분리·가중 평균·페이지·실제 Electron IPC/UI 검증도 수행했습니다. 실제 카메라 정확도나 의학적 타당성을 증명하지 않습니다. 자세한 증거는 [검증 기록](ai-workflow/work-items/2026-09-19/jangwon/statistics/09_VERIFICATION.md)에 있습니다.
