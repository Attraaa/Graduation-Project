# AI 총평

사이드바의 **AI 총평**에서 7일 또는 30일을 선택하면 모델에 보낼 집계를 확인할 수 있습니다. **총평 받기**를 누르면 로그인한 앱이 HTTPS로 AWS의 `POST /api/ai/review`를 호출합니다. AWS는 요청을 검증하고 비공개 연결로 미니 PC에 짧은 한국어 기록을 전달합니다. 앱은 점수와 증감을 계산해 표시하고, 미니 PC가 기록에 맞춰 작성한 습관 조언을 덧붙입니다. 모델 응답에서 조언을 얻지 못하면 기본 제안임을 화면에 표시합니다.

## 측정 기록

- 데스크톱 앱은 계정별 `posture-timelines/account-<id>/`에 상체 점수를 1초 단위 JSONL로 기록하고, 측정이 끝나면 `.summary.json`을 저장합니다. 브라우저에서는 IndexedDB를 사용합니다.
- 목과 좌우 균형의 평균은 각 항목의 유효 측정 시간으로 가중합니다. 직전 기간과 비교할 때도 같은 측정 기준을 사용합니다. 이전 버전에서 저장한 어깨 점수는 어깨로 표시합니다.
- 안구의 깜빡임 통계와 키보드의 입력별 집계도 측정이 끝나면 이 기기의 IndexedDB에 보관합니다. 각 항목의 로컬 자료가 없으면 기존 서버 통계를 사용합니다. 설정에서 측정 기록을 삭제하면 현재 계정의 로컬 자료도 지웁니다.
- 모델에는 기간 집계와 최근 측정의 목 점수 구간을 보냅니다. 영상, 개별 키 입력 순서, 원본 JSONL, 로그인 정보는 미니 PC에 전달하지 않습니다.

## 서버 설정

AWS 서버의 `MOTI_REVIEW_GATEWAY_URL`에 비공개 HTTPS 게이트웨이의 전체 `/review` 주소를 설정합니다. 미니 PC는 `{"record":"…"}`를 받아 Ollama로 총평을 작성하고 `{"summary":"…","model":"…"}`을 반환합니다. 로그인 검증과 계정당 시간당 10회 제한은 AWS에서 처리합니다. 게이트웨이가 바쁘거나 응답 시간이 초과되면 앱에 다시 시도할 수 있는 메시지를 표시합니다.

기본 API 서버에 총평 경로가 포함되어 있습니다. 총평만 별도 배포할 때는 `npm run build` 후 `PORT`를 지정하여 `node dist/reviewServer.js`로 루프백에서 실행하고 nginx의 해당 경로를 연결합니다. 프록시 읽기 제한은 100초 이상으로 설정합니다.
