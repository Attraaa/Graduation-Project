# AI 총평

2026-10-17에 추가했습니다. 통계와 같은 기간(7일·30일)의 집계를 Claude에 보내 짧은 총평(총평·잘한 점·개선할 점)을 받습니다. 최종 위치가 정해지지 않아 사이드바의 별도 메뉴 **AI 총평**(`/ai-review`)에 둡니다.

## 흐름

- 화면 `front/src/pages/AiReview.tsx`는 통계 화면과 같은 `useStatisticsData`로 상체·안구·키보드 기록을 불러옵니다. `features/ai-review/input.ts`가 통계에 보이는 수치를 요청 형태로 바꿉니다. 세 출처가 모두 불러와져야 보낼 수 있습니다.
- 보내기 전에 "AI에게 보내는 기록"에서 요청 값을 모두 문장으로 보여 줍니다. 사용자가 **총평 받기**를 눌러야 서버에 요청합니다.
- 서버 `POST /api/ai/review`(로그인 필요)는 숫자와 알려진 키 코드만 받습니다(`server/src/services/aiReview.ts`). 서버의 API 키로 Claude를 호출해 `{ summary, strengths, improvements, model, generatedAt }`을 돌려줍니다.
- 총평은 서버와 기기 어디에도 저장하지 않습니다. 화면을 벗어나면 다시 받아야 합니다.

## 키 설정

키 보관 원칙, 현재 비용 통제의 한계와 외부 테스트 전 완료 기준은 [보안 문서](security.md)를 따릅니다. 구현 대기 항목은 [로드맵](roadmap.md#ai-보안비용-통제--남은-작업-2026-10-30)에 기록합니다. 개인 API 키(BYOK)는 보류된 선택 기능이며 현재 구현은 서버 키 방식입니다.

- `server/.env`에 `ANTHROPIC_API_KEY=<키>`를 넣고 서버를 다시 시작합니다. 키 이름과 설명은 `server/.env.example`에 있습니다.
- 키가 없으면 서버는 정상으로 시작하고 이 경로만 503 "설정 필요"로 응답합니다. 키가 틀리면 같은 안내를 503으로 보여 줍니다.
- `front/.env`에는 넣지 않습니다. 이 파일은 git에 올라가고 `VITE_` 값은 앱 번들에 그대로 들어갑니다.
- 배포 서버도 그 서버의 env에 키를 넣어야 합니다. 서버 빌드는 패키지를 번들하지 않으므로(`--packages=external`) 배포 서버에서 `npm ci`로 `@anthropic-ai/sdk`를 설치해야 합니다.

## 모델과 호출

- 모델은 `claude-opus-5-5`입니다(서비스 상수 `AI_REVIEW_MODEL`). 노력 수준 `low`, JSON 스키마 구조화 출력, 최대 출력 16,000토큰입니다.
- 안전 분류기가 거절하면 같은 호출 안에서 Anthropic이 권장하는 대체 모델로 다시 시도합니다(`fallbacks: "default"`, beta `server-side-fallback-2026-07-01`). 이때 응답의 `model`은 대체 모델 이름입니다.
- 한 번 시도의 시간 제한은 40초이고 1회 재시도합니다. 화면은 90초까지 기다립니다.
- 계정당 1시간에 10번까지 받을 수 있습니다. 서버 메모리 기준이라 재시작하면 초기화됩니다. 전체 비용 상한은 Claude Console(https://platform.claude.com)의 지출 한도로 정합니다.

## 보내는 데이터

- 기간 길이
- 목·어깨 평균 점수와 직전 기간 값, 측정 시간·횟수, 기준 이탈 횟수와 시간 비율, 측정 품질
- 깜빡임 빈도(직전 기간 포함)와 유효 관찰 시간
- 키보드 훈련 점수(직전 기간 포함)·판정 가능 비율·일관성·판정 수, 다른 손가락을 자주 쓴 키(10회 이상 판정, 최대 3개)와 그 비율

영상, 키 입력 원문, 계정 정보는 보내지 않습니다. 요청에는 자유 문장이 없으므로 화면 입력이 지시문으로 섞이지 않습니다.

## 한계

- 총평은 기록 수치에 대한 참고용 문장이며 의학적 판단이 아닙니다. 점수의 의미는 [evaluation.md](evaluation.md)를 따릅니다.
- 2026-10-17 현재 실제 키로 호출해 문장 품질을 확인하지 않았습니다. 자동 검사는 SDK 클라이언트를 대역으로 바꿔 요청 형태와 오류 처리를 확인합니다.
- 결정 기록은 [product-decisions.md](product-decisions.md) D7을 따릅니다.
