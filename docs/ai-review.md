# AI 총평

사이드바의 **AI 총평**에서 7일 또는 30일을 선택하면 모델에 보낼 집계를 확인할 수 있습니다. **총평 받기**를 누르면 로그인한 앱이 HTTPS로 AWS의 `POST /api/ai/review`를 호출합니다. AWS는 요청을 검증하고 비공개 연결로 미니 PC에 짧은 한국어 기록을 전달합니다. 앱은 점수와 증감을 계산해 표시하고, 미니 PC가 기록에 맞춰 작성한 습관 조언을 덧붙입니다. 모델 응답에서 조언을 얻지 못하면 기본 제안임을 화면에 표시합니다.

## 화면 구성

2026-11-28부터 총평은 아래 순서로 보여 줍니다. 사용자가 "글이 적고 내용이 빈약하다"고 판단해 정한 구성입니다. 숫자·판단·문단은 모두 `server/src/services/reviewFacts.ts`가 만들고, 모델이 고른 습관 문장만 총평 문단의 마지막 문장으로 붙습니다.

- **한 줄 요약**: 가장 크게 오르거나 내린 점수로 고릅니다(예: "목 점수와 키보드 점수가 함께 오른 한 주였어요.").
- **최근 7일(30일) 총평**: 측정한 날과 측정량, 직전 기간과의 점수 비교, 가장 크게 오른 점수, 분당 깜빡임 변화, 기준 이탈이 잦았던 시간대나 날짜 흐름 하나, 미니 PC가 고른 습관.
- **영역별 문단**: 측정한 영역만 보여 줍니다.
  - 목·좌우 균형(예전 기기 기록은 목·어깨): 평균 점수, 두 점수 차이, 날짜별 최고·최저와 흐름, 시간대별 최고·최저(관찰 30분 이상인 시간대만), 가장 길게 이어진 측정.
  - 서버 통계일 때는 기준에서 벗어난 횟수·시간과, 관찰 시간에 비해 이탈이 잦은 시간대를 더합니다. 횟수만 보면 오래 측정한 시간대가 늘 잦아 보이기 때문입니다.
  - 이 기기의 측정 요약일 때는 가장 최근 측정의 목 점수 구간을 더합니다. 기기 요약에는 이탈 횟수가 없어 이탈 문장은 나오지 않습니다.
  - 키보드: 판정한 입력, 훈련 점수, 날짜별 최고·최저, 일관성, 권장과 다른 손가락을 자주 쓴 키, 판정 가능 비율과 카메라 안내.
  - 깜빡임: 관찰 시간, 분당 횟수, 직전 기간과의 변화. 점수가 아니라 참고 기록이라는 문장을 붙이고 좋다·나쁘다는 평가하지 않습니다.
- **잘한 점 / 아쉬운 점 / 다음 목표**: 각각 최대 3개입니다. 다음 목표는 아쉬운 점에서 나옵니다(예: "오후 3시 무렵에 한 번씩 기준 자세 확인하기"). 점수로 고를 것이 없을 때는 측정한 기록을 잘한 점으로, 다음 측정에서 이어 볼 일을 목표로 둡니다.
- 측정이 부족한 영역은 참고용이라는 안내를 붙이고, 그 영역의 점수로는 잘한 점·아쉬운 점을 고르지 않습니다.

기준값(점수 변화 2점, 높음 80점·낮음 60점, 기준 이탈 시간 10%·30%, 측정 품질 70%, 상체 30분·깜빡임 10분·키보드 200회 등)은 `reviewFacts.ts` 맨 위에 모아 둔 화면 안내용 잠정값이며 건강 기준이 아닙니다. 응답은 `{ headline, sections[{ key, title, text }], strengths, weaknesses, goals, caution, model, adviceSource, generatedAt }`이고, 2026-11-28 이전 앱을 위해 `summary`(총평 문단)와 `improvements`(아쉬운 점, 없으면 다음 목표)도 함께 보냅니다.

## 측정 기록

- 데스크톱 앱은 계정별 `posture-timelines/account-<id>/`에 상체 점수를 1초 단위 JSONL로 기록하고, 측정이 끝나면 `.summary.json`을 저장합니다. 브라우저에서는 IndexedDB를 사용합니다.
- 목과 좌우 균형의 평균은 각 항목의 유효 측정 시간으로 가중합니다. 직전 기간과 비교할 때도 같은 측정 기준을 사용합니다. 이전 버전에서 저장한 어깨 점수는 어깨로 표시합니다.
- 안구의 깜빡임 통계와 키보드의 입력별 집계도 측정이 끝나면 이 기기의 IndexedDB에 보관합니다. 각 항목의 로컬 자료가 없으면 기존 서버 통계를 사용합니다. 설정에서 측정 기록을 삭제하면 현재 계정의 로컬 자료도 지웁니다.
- AWS에는 기간 집계, 측정한 날 수, 날짜별·시간대별 점수, 가장 길게 이어진 측정, 최근 측정의 목 점수 구간을 보냅니다. 보내기 전 화면에서 모두 보여 주며 날짜별·시간대별 값은 접힌 목록에 있습니다. 미니 PC에는 앱이 이 값으로 쓴 한 줄 요약·총평 문장·목록과 고를 수 있는 습관만 전달합니다. 영상, 개별 키 입력 순서, 원본 JSONL, 로그인 정보는 미니 PC에 전달하지 않습니다.

## 서버 설정

AWS 서버의 `MOTI_REVIEW_GATEWAY_URL`에 비공개 HTTPS 게이트웨이의 전체 `/review` 주소를 설정합니다. 미니 PC는 `{"record":"…"}`를 받아 Ollama로 총평을 작성하고 `{"summary":"…","model":"…"}`을 반환합니다. 로그인 검증과 계정당 시간당 10회 제한은 AWS에서 처리합니다. 게이트웨이가 바쁘거나 응답 시간이 초과되면 앱에 다시 시도할 수 있는 메시지를 표시합니다.

기본 API 서버에 총평 경로가 포함되어 있습니다. 총평만 별도 배포할 때는 `npm run build` 후 `PORT`를 지정하여 `node dist/reviewServer.js`로 루프백에서 실행하고 nginx의 해당 경로를 연결합니다. 프록시 읽기 제한은 100초 이상으로 설정합니다.
