대상: `codex/posture-reliability` → `main` 테스트용 PR. 기준 main: `7753e71`. 이 문서는 병합을 요구하지 않습니다.

## 실행

기존 작업 폴더와 다른 새 폴더에 테스트 브랜치를 받습니다. Windows x64 / PowerShell 기준:

```powershell
git clone --branch codex/posture-reliability --single-branch https://github.com/Attraaa/Graduation-Project.git Graduation-Project-posture-test
cd Graduation-Project-posture-test
.\setup.cmd
.\moti.cmd app
```

Git을 사용하지 않으면 GitHub에서 `codex/posture-reliability` 브랜치를 선택한 뒤 **Code → Download ZIP**으로 받아 별도 폴더에 풀고 `setup.cmd`, `moti.cmd`를 순서대로 실행합니다. 첫 설치에는 인터넷이 필요하고 도구와 의존성을 프로젝트 안에 설치합니다. 기본 측정에는 골반이 보이지 않아도 됩니다.

학습된 작은 몸통 모델은 `front/src/features/posture/trunkModel.ts`에 포함되어 있어 **데이터 다운로드나 재학습 없이 앱 테스트가 가능합니다.** 실제 자세/안구 모델도 setup에서 준비합니다. 최초 모델 초기화는 기기에 따라 1분 이상 걸릴 수 있으며 화면의 준비 단계와 경과 시간을 확인합니다.

로그인·통계 저장은 기존 `front/.env`의 API 서버를 사용합니다. 별도 테스트 서버를 쓰려면 `front/.env.local`에 팀이 지정한 `VITE_MOTI_API_URL`을 설정하고 재실행합니다. 이 브랜치에서 실행해도 로그인한 서버에 테스트 기록이 저장될 수 있으므로 팀 테스트 계정을 사용하세요. 서버 주소나 계정 비밀번호를 PR 댓글에 남기지 않습니다. DB 스키마 변경이나 SQL 실행은 필요 없습니다.

## 확인할 동작

상체를 시작하고 편안하게 화면을 보는 자세로 새 기준을 수집합니다. 안구 안내에 따라 열린 눈과 깜빡임 보정도 마칩니다. 통증을 유발할 만큼 목을 내밀거나 그 자세를 유지할 필요는 없습니다.

| 동작 | 확인할 결과 |
| --- | --- |
| 편한 기준 자세 유지 | 목·어깨 점수가 허용 범위에 머무는지 |
| 자세를 유지하며 의자 전체를 조금 앞뒤로 이동 | 함께 커진 얼굴·어깨만으로 목 점수가 크게 떨어지지 않는지 |
| 어깨를 유지하고 머리만 편한 범위에서 전진 | 목 점수가 반응하는지. 모델 제외 기하 조건이 기본 약 84점 이하이면 5초 후 초당 2점 추가 감점 |
| 머리 전진이 기본 약 80점인 상태 유지 | 조건을 계속 만족할 때 시작 후 10초 약 70점, 20초 약 50점. 실제 좌표 변화와 움직임 보호에 따라 차이 가능 |
| 편한 자세로 복귀 | 복귀를 1초 확인한 후 추가 감점이 해제되는지 |
| 작은 어깨 기울임 → 더 큰 기울임 | 작은 변화는 허용하고 큰 기울임에서 감점이 가팔라지는지. 화면상 기준 대비 6도는 원점수 약 63점, 8도는 약 21점(다른 변화 0 기준) |
| 잠시 얼굴 가림·회전·일시정지 | 미관측 상태에서 점수나 시간 감점이 새로 쌓이지 않는지. 재개만으로 100점이 되지 않는지 |
| 기준 다시 잡기·중지·재시작 | 이전 추가 감점이 새 기준/새 세션에 넘어오지 않고 카메라가 정상 해제되는지 |
| 홈/상체 상세 이동 | main의 목·어깨·깜빡임 카드와 추이 구조를 유지하는지 |

## 이번에 구현하지 않은 항목

약간 고개를 돌린 상태, 위·아래에 설치한 카메라 대응은 [검토 문서](posture-viewpoint-proposal.md)에만 정리했습니다. 현행 품질 보류는 그대로입니다. 자세 알림 설정은 저장되지만 Windows 알림·경고음 실행에는 연결되지 않았고, 안구 안내 조건은 내부 집계만 됩니다.

점수는 개인 기준 대비 변화와 지속 시간을 나타내는 시험 정책입니다. 체형별 신체 부담이나 진단의 동일한 수치로 해석하지 않습니다. 모델은 골반/개인 기준/품질 조건을 만족할 때만 제한적으로 보조하며, 골반이 없는 구도에서는 기여가 0입니다.

## 피드백과 개발 검사

피드백에는 카메라 위치(정면/위/아래), 대략적인 거리, 수행 동작, 초기/유지 후 점수, 경과 시간, 복귀 여부, 보류 안내를 적어 주세요. 개인 영상 공유는 필수가 아닙니다.

개발 검사: `moti.cmd check`. 현재 로컬 검증은 프론트 240개, 서버 44개, Python 16개 및 UI/Electron 빌드 통과입니다. MySQL 통합 1개는 테스트 접속 설정 부재로 건너뛰었습니다. 브라우저 가상 입력은 확인했지만 다양한 실제 체형·구도의 정확도 검증은 남아 있습니다.
