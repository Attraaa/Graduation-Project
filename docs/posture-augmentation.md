## 현재 선택

main의 가중합 → 선형 환산 → 움직임 보호 → 시간 평균 구조를 유지합니다. 목 비중은 **머리 35%·몸통 보조 25%·높이 감소 40%**로 되돌리되, 어깨가 커졌다는 이유로 몸통 점수를 내리지 않습니다. 기본 측정은 얼굴·귀·양어깨만 필요합니다. MediaPipe Full과 기존 안구 모델을 유지하며 추가 영상 모델이나 서버 요청은 없습니다.

직전 v4는 귀 폭/어깨 폭만으로 전진을 계산했습니다. 실제 카메라 접근은 사진 확대와 달리 원근 변화가 생기고, 귀 위치가 둔하게 추적되면 머리만 전진한 것을 놓칩니다. v5는 원근 허용 범위와 기존 MediaPipe의 코·귀 추정 깊이를 추가합니다.

## 관측 → 점수 산식

`E`=귀 폭, `S`=어깨 폭, `H`=귀–어깨 높이, `0`=개인 기준. 모두 화면 픽셀 또는 비율이며 실제 길이가 아닙니다.

- 공통 크기 변화: `c=abs(S/S0-1)`, 원근 허용 `t=min(0.08,0.3*c)`.
- 머리 폭 신호: `w=max(0,(E/E0)/(S/S0)-1-t)`.
- 깊이 신호: 코와 귀 중점 각각의 `(z-어깨중점z)/3D어깨폭`을 기준과 비교합니다. 두 값 모두 앞으로 변한 양 중 작은 값에서 0.02 잡음 허용을 뺍니다. `max(0,1-c/0.08)`을 곱해 어깨 크기가 8% 이상 변하면 깊이 보조를 끕니다.
- 머리 입력: `2*max(w,깊이신호)`. 개인 기준의 모든 표본에서 깊이가 유효하고 각 범위가 0.08 이하여야 깊이 기준을 만듭니다. 기준/현재 깊이가 없거나 코·귀 방향이 불일치하면 폭 신호만 씁니다.
- 높이 변화: `h=H0/S0-H/S`. `sign(h)*max(0,abs(h)-t)`의 양수 부분을 목에, 절댓값을 어깨에 사용합니다.
- 어깨 기울기: 현재/기준의 부호 있는 높이차/어깨거리에 각각 asin을 적용한 각도 차이 절댓값(라디안)입니다.
- 목 편차: `0.35*머리 + 0.25*모델보조 + 0.4*높이감소`. 0.04 이하 100점, 0.20 이상 0점, 사이는 선형 환산합니다.
- 어깨 편차: `0.7*비선형기울기입력 + 0.3*0.8*상하변화`. 기울기 입력은 4도 초과부터 지수 항을 더합니다([상세 산식](posture-score-tuning.md)). 작은 어깨 변화에 대한 직전 완화 설정(0.04/0.22)을 유지합니다.

상수는 `scoreSettings.ts`, 상대 기하는 `relativeHead.ts`, 순수 수집/관측은 `calibration.ts`/`observation.ts`가 소유합니다. 위 허용값과 반응 ×2는 학습된 의학 기준이 아닌 **제품 시험 설정**입니다. 함께 이동하면서 목도 내미는 복합 동작은 덜 민감할 수 있습니다. 추정 깊이 또한 실제 센서 깊이가 아니므로 오차가 남습니다.

3표본/250ms 중앙값, 회전·가림 보류, 0.5어깨폭/초 움직임 보호, 정지 2초 유예, 초당 35점 감점, 1초 복귀 확인을 유지합니다. 필터는 회전·누락·공백·기준 변경에서 비웁니다. 잘못 잡은 개인 기준을 올바른 자세로 교정하지 않습니다.

## 학습 모델을 결합하는 범위

MultiPosture 13명/4,794행의 코·어깨·골반 world 좌표로 학습한 **7→16→4 몸통 분류기**를 제한적 보조로 연결했습니다. 골반이 보이지 않아도 기본 점수는 동작하며, 골반을 가짜 좌표로 채우지 않습니다.

1. 개인 기준 수집 전체에서 모델이 upright로 채택되어야 해당 세션에 모델 보조를 허용합니다.
2. 현재 코·어깨·골반이 실제 영상 안에 있고 가시성 ≥0.8, 학습 범위, softmax ≥0.85, 상위 차이 ≥0.25를 통과해야 합니다.
3. forward가 1초 연속 확인되고, 필터 후 머리/높이 변화가 함께 있어야 보조합니다.
4. 보조 입력은 `0.08*min(1,max(머리,높이감소)/0.2)`로 제한합니다. 목 원점수에 최대 **12.5점** 추가 영향이며, 모델만으로는 감점하지 않습니다. 어깨에는 영향이 없습니다.
5. 골반 가림·분류 보류·시간 단절이면 즉시 보조를 0으로 돌립니다. 개발용 근거 화면은 이를 '보조 보류/기본 계산'으로 표시합니다. 기본 측정까지 중단하지 않습니다.

따라서 통상적인 얼굴·어깨 구도에서는 이 학습 모델의 점수 기여가 **0**인 것이 정상입니다. 개선의 중심은 상대 관측이며, 모델이 주된 개선 원인이라고 소개하지 않습니다. 보조도 실제 Moti 구도에서 개선을 검증하지 못한 시험 기능입니다. 학습 결과/한계는 [모델 카드](posture-model-card.md)를 따릅니다.

점수 `upper-body-*-v6-<해시>`, 습관 `weighted-reference-deviation-v6[:s민감도]`. 기준 스키마 v2의 세션 메모리에 선택적 깊이/모델 기준 필드만 추가했고 API·DB 구조는 그대로입니다. 저장에는 보호 적용 점수만 보내며 원시 영상/좌표/모델 분류는 전송하지 않습니다. 이전 정책의 통계는 섞지 않습니다.

## 다음 정확도 검증과 학습 순서

현재의 제한된 몸통 보조를 주 판정으로 확대하려면 골반 없는 Moti 구도로 수집한 독립 자료와 새 특징 설계가 필요합니다. 현재 몸통 모델의 골반을 가짜 좌표로 채우거나 가시성 검사를 끄지 않습니다. 권장 파일은 `reports/posture-augmentation/moti-validation/` 아래 `manifest.csv`(동의 여부, 익명 참가자/세션/카메라 ID, 동작, 시작/끝 시각, 독립 정답)와 로컬 영상·랜드마크입니다. 실제 영상을 자동 수집하는 기능은 이번에 넣지 않았습니다.

1. 최소 예비시험으로 새로운 참가자 10명 이상, 각 2회 세션, 두 거리/조명에서 위 3~6번 동작을 촬영합니다. 실제 실험 규모는 편차와 요구 정확도에 따라 늘립니다.
2. 비교 전 정답과 합격 기준을 고정합니다. 예: 정상 유지에서의 오경고, 실제 변화 누락, 보류율, 복귀 지연을 각각 보고하고 어느 하나를 숨기고 정확도만 발표하지 않습니다.
3. 동일 프레임으로 main(v3)/v6/보조 모델을 비교합니다. 참가자와 세션이 학습·검증에 동시에 들어가지 않게 하고, 가림·회전·거리별 실패 사례를 봅니다. 최종 시험 사람은 튜닝에 쓰지 않습니다.
