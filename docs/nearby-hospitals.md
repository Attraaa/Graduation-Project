# 주변 병원 찾기

2026-11-14에 추가했습니다. AI 총평 화면(`/ai-review`) 맨 아래에 있습니다. 사용자가 진료과(정형외과·재활의학과·신경외과·안과)를 고르고 동네 이름이나 주소를 입력하거나 **현재 위치**를 누르면, 카카오 로컬 API로 반경 5km 안의 병원을 거리순으로 최대 15곳 찾아 카카오 지도와 목록으로 보여 줍니다. 결정 기록은 [제품 결정](product-decisions.md)의 2026-11-14 항목을 따릅니다.

## 원칙

- 점수나 총평과 연결하지 않습니다. 이 칸은 점수와 상관없이 항상 같은 자리에 있고, AI나 점수가 병원을 권하지 않습니다.
- "불편감이나 통증이 계속되면 전문의와 상담하세요"와 "카카오 지도에서 찾은 병원을 거리순으로 보여 줘요. 추천이나 진료 판단이 아니에요"를 함께 보여 줍니다.
- 병원 이름은 카카오 검색 결과만 씁니다. LLM이 병원을 만들거나 고르지 않습니다.

## 흐름

- 화면은 `front/src/features/hospitals/NearbyHospitals.tsx`에 있습니다. 지도 SDK는 로그인 화면과 출처가 격리된 iframe에서 실행됩니다. 지도에는 검색 중심 좌표와 병원 이름·좌표만 전달합니다.
- 로그인한 앱은 `POST /api/hospitals`의 JSON 본문에 `department`와 `query` 또는 `lat`·`lng`를 보냅니다. 기존 설치본의 GET 요청도 호환됩니다. 새 설치본을 배포하기 전에 POST 경로가 있는 서버를 먼저 반영합니다.
  - 입력한 위치는 카카오 주소 검색으로 먼저 찾고, 없으면 키워드(장소 이름) 검색으로 중심 좌표를 정합니다. 둘 다 없으면 404입니다.
  - 병원은 키워드 검색으로 찾습니다(`query`=진료과, `category_group_code=HP8`, 반경 5,000m, 거리순, 15개).
  - 응답 형식은 `{ center: { lat, lng, label }, hospitals: [{ id, name, category, address, phone, distance, lat, lng, url }] }`입니다. 장소 링크는 https로 바꿔 돌려줍니다.
  - 오류 응답은 다음과 같습니다. 로그에는 카카오의 상태 코드만 남깁니다.
    - 서버에 키가 없음: 503
    - 카카오 인증 실패(키나 카카오맵 사용 설정): 503
    - 카카오 쿼터 초과: 429
    - 연결 실패: 504
    - 그 밖의 오류: 502
- 지도와 목록은 서로 연결되어 있습니다. 목록을 누르면 지도에 이름이 뜨고, 마커를 누르면 목록이 강조됩니다. 진료과를 바꾸면 같은 위치로 다시 찾습니다. 창 크기가 바뀌면 지도를 다시 배치하고(`relayout`) 같은 범위를 보여 줍니다.
- "카카오맵에서 보기" 링크는 Electron이 `https://place.map.kakao.com/<숫자>`일 때만 기본 브라우저로 엽니다(`front/electron/externalLinks.ts`). 지도 안 카카오 로고 링크를 포함해 다른 주소는 지금처럼 열리지 않습니다.

## 위치와 개인정보

- 새 설치본은 위치를 URL에 넣지 않습니다. 기존 설치본의 위치도 프록시 로그에 남지 않도록 병원 경로에는 `$request_uri`나 `$args` 대신 경로 `$uri`, 응답 상태, 처리 시간만 기록하는 포맷을 적용합니다.
- 현재 위치는 화면에서 소수점 둘째 자리(약 1km)로 반올림해 보내고, 서버도 한 번 더 반올림합니다. 입력한 위치는 사용자가 적은 글자를 그대로 카카오에 보냅니다.
- 위치는 Moti 서버를 거쳐 카카오 로컬 API로 전달되며, 카카오의 처리 방침이 적용됩니다.

## 키 설정

1. [Kakao Developers](https://developers.kakao.com)에서 앱을 만들고 **카카오맵 → 사용 설정**을 ON으로 바꿉니다. 2026-07-21 정책상 무료 쿼터는 개발자 계정에서 카카오맵을 처음 켠 앱 하나에만 주어집니다.
2. **REST API 키**는 `server/.env`의 `KAKAO_REST_API_KEY`에 넣습니다. 서버에만 두며, 없으면 이 경로만 503이고 나머지 기능은 그대로 동작합니다.
3. **JavaScript 키**는 `front/.env.local`의 `VITE_KAKAO_JS_KEY`에 넣습니다. 이 파일은 git에서 제외되지만 키는 빌드 결과물에 들어갑니다.
   - 같은 키의 **JavaScript SDK 도메인**에 `http://localhost:5173`(개발)과 `file://`(설치 앱)을 등록해야 지도가 뜹니다.
   - 키가 없거나 지도 SDK를 불러오지 못하면 지도 없이 목록만 보여 줍니다.
4. 무료 쿼터(2026-11 기준)는 지도 하루 30만 건, 키워드·주소 검색 각 하루 10만 건, 전체 월 300만 건입니다. 비즈월렛(결제 수단)을 연결하지 않으면 과금되지 않습니다.

## 검증 (2026-11-14, macOS)

- **지도 SDK**: 등록 도메인인 `http://localhost:5173`과 `file://`에서는 지도가 떴습니다. 등록하지 않은 `http://localhost:5198`에서는 카카오가 SDK를 막아, 도메인 검사가 실제로 동작함을 확인했습니다.
- **REST 키**: 서울시청 반경 3km 정형외과 검색이 200으로 응답했습니다.
- **화면**: browser 모드 빌드를 시험용 Electron에서 `file://`와 `http://localhost:5173`으로 열고, 실제 병원 라우트와 카카오 데이터로 20개 항목을 확인했습니다. 지도 마커와 목록, 선택한 병원 이름 표시, 장소 링크 요청, 진료과 전환, 없는 위치 안내, (가짜 좌표를 넣은) 현재 위치, 다크 테마와 400px 창에서 가로 스크롤 없음, 창 크기를 바꾼 뒤에도 마커가 보이는지를 봤습니다. 창 크기를 바꾸면 지도가 어긋나던 문제는 이때 발견해 `relayout`으로 고쳤습니다.
- **아직 확인하지 않은 것**
  - Windows 설치본에서의 실기기 동작
  - Windows에서의 실제 현재 위치(Electron 위치 API)
  - 운영 서버 배포(운영 서버에 키를 아직 넣지 않음)

## 한계

- 계정별 요청 제한이 없습니다. 카카오 무료 쿼터를 넘으면 그날은 429로 막힙니다.
- 진료과는 카카오 키워드 검색 결과라 다른 진료과가 섞일 수 있습니다. 예를 들어 마취통증의학과가 정형외과로 분류되어 나오기도 합니다.
- 현재 위치는 OS 위치 설정에 따라 실패할 수 있고, 그때는 주소로 찾으라고 안내합니다.
- JavaScript 키는 앱에 들어가는 공개 키라서, 콘솔의 도메인 제한으로만 보호됩니다. `file://`과 `localhost`는 누구나 만들 수 있는 주소라, 키가 알려지면 다른 사람이 같은 키로 지도를 띄워 쿼터를 쓸 수 있습니다.
