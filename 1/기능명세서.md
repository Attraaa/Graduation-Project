# PostureAI (VDT 증후군 교정 프로그램) 기능 명세서

## 1. 프로젝트 개요
**PostureAI**는 컴퓨터 작업 시간이 긴 현대인들의 VDT 증후군(거북목, 손목 터널 증후군 등)을 예방하고 교정하기 위한 데스크톱 애플리케이션입니다. AI 카메라 분석을 통해 사용자의 자세를 실시간으로 모니터링하고 피드백을 제공합니다. 

- **플랫폼:** Windows 데스크톱 앱 (Electron 기반)
- **프론트엔드:** React 19, Tailwind CSS, Vite
- **디자인 테마:** 듀오링고(Duolingo) 스타일의 직관적이고 친근한 둥근 UI (Vibrant Colors, Rounded-3xl)

### 2.2. 사용자 인증 (Authentication)

|:---|:---|:---|
| **로그인 (Login)** | 이메일과 비밀번호를 입력하여 서비스에 접속. (현재 `localStorage` 기반 가상 인증 처리) | 유효성 검사 포함 |

### 2.3. AI 모니터링 대시보드 (Dashboard)

## 3. UI/UX 디자인 시스템 (Design System)
- **Primary Color:** `#58cc02` (Vibrant Green - 긍정, 활성화, 완료)
- **Secondary Color:** `#1cb0f6` (Vibrant Blue - 정보, 선택)
- **Warning Color:** `#ffc800` (Yellow - 주의, 알림), `#ff4b4b` (Red - 위험, 에러)
- **Shape & Form:** 
  - 모든 버튼과 카드는 `border-radius: 1.5rem (rounded-3xl)` 적용.
  - 입체감을 주기 위해 하단에 `border-b-4` 형태의 굵은 그림자 테두리 사용.
  - 호버(Hover) 시 카드가 살짝 눌리는 듯한 `translate-y-1` 애니메이션 적용.
- **Typography:** `Inter`, `system-ui` (가독성이 높고 둥근 느낌을 주는 산세리프 폰트)
- **레이아웃:** 좌측 반응형 사이드바(Sidebar) 네비게이션 + 우측 메인 콘텐츠 영역 (Flexbox 활용)
