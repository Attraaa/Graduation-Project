Moti 개인정보 및 카메라 사용 안내

1. 계정
가입 시 아이디, 닉네임, 복구 이메일, 비밀번호를 받습니다. 서버에는 비밀번호 해시를 보관합니다. 복구 이메일은 가입 확인, 아이디 찾기, 비밀번호 재설정에 씁니다. 메일 발송 시 수신 주소와 안내 또는 인증 코드를 설정된 메일 서비스로 전달합니다.

2. 카메라와 키보드 학습
학습을 시작할 때 선택한 카메라의 영상과 자세·손·눈 인식 결과를 이 기기에서 처리합니다. 승인한 앱의 키 입력은 키보드 학습 중 관찰하며, 미승인 앱은 관찰하지 않습니다. 원본 영상, 얼굴 랜드마크, 입력 문장과 개별 입력 순서는 서버에 저장하지 않습니다. 자세와 눈의 측정 집계, 키별 판정 횟수와 분석 품질 집계를 학습이력과 통계에 씁니다. 설정에서 승인 앱 목록을 확인하거나 변경할 수 있습니다.

3. 기록과 AI 총평
학습이력과 통계 집계는 Moti 서버에 저장합니다. 초 단위 상체 관찰 점수와 일부 총평용 집계는 이 기기에도 저장합니다. AI 총평을 요청할 때 측정 요약과 판정 집계가 Moti 서버를 거쳐 미니 PC의 모델로 전달됩니다. 카메라 영상, 입력 문장, 계정 이름, 복구 이메일은 모델 요청에 포함하지 않습니다. 설정의 통계 삭제로 현재 계정의 서버 기록과 이 기기의 총평용 기록을 지울 수 있습니다.

4. 주변 병원 검색
사용자가 검색을 요청할 때 입력한 주소나 약 1km 단위의 현재 위치를 Moti 서버를 거쳐 카카오에 전달합니다. 지도용 병원 위치와 이름을 카카오 지도에 표시합니다. 검색에 입력한 위치는 Moti 학습 기록에 저장하지 않습니다.

5. 진단 로그
앱이 멈추거나 연결이 끊기는 원인을 찾기 위해 오류 종류, 실행 상태, 화면 장치 정보와 메모리 값을 이 기기에 기록합니다. 영상, 입력 문장, 이메일, 위치 검색값, 인증 토큰은 이 로그에 기록하지 않습니다. 시작할 때 14일 지난 진단 파일을 지웁니다.
